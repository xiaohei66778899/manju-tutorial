选题库 · 题材方向

题材方向:平台差异 · 饱和度 · 复用机会

一、平台题材热度差异(2026 年 8 月)

同一题材在不同平台表现差异极大。抖音、红果、快手三大平台的题材偏好底层逻辑不同:抖音偏向刷到的爽(feed 流推荐),红果偏向追剧的爽(付费墙拉动),快手偏向短平快(单集 60-80 秒)。

平台主打类型TOP 题材(8 月)单部播放增量均值适配分账模式
抖音原生端AI 仿真人剧 / 3D 漫混合战神 · 都市异能 · 萌宝 · 重生413.2 万(6 月均值)IAA 单集解锁 · 创作者分账

关键差异解读(为什么红果 100% 都是 3D 漫?)

  • 红果付费墙拉动剧情密度:红果 IAP 模式下,用户付费解锁下一集,3D 漫的"视觉爽感"可弥补剧情薄;AI 仿真人剧的剧情压力更大,但 3D 漫制作边际成本已降至每分钟数百元,DataEye 2026.08性价比反转。
  • 抖音 IAA 模型偏向真人感:抖音刷到的"能不能看下去"取决于前 3 秒,AI 仿真人剧的人物视觉真实度更接近传统短剧用户预期。3D 漫在抖音端仍然有 62 部进入百强,但占比明显低于红果。DataEye 2026.08
  • 8 月收租老汉题材进入 TOP15:这是新出现的细分方向,本质是"乡土+爽文+小额财富"的复合题材,在红果和快手两端同时起量。

二、AI 仿真人剧 vs 3D 漫 vs 2D 漫:题材适配度

三种类型的题材适配不是平均分布,每个类型有自己的"舒适区"和"塌房区"。

类型最佳题材慎选题材制作成本(每分钟)改编成本
AI 仿真人剧都市情感 · 现代职场 · 校园 · 古装言情 · 战神 · 都市异能武侠动作(动作戏崩) · 末日废土(场景复杂) · 萌宝(婴儿脸崩)800-1200 元低(角色复用度高)
3D 漫战神 · 玄幻 · 末世 · 机甲 · 山猎 · 赶海 · 收租老汉 · 都市异能细腻情感戏(角色表情僵硬) · 校园文戏(缺乏代入感)300-800 元中(角色模型需重训)
2D 漫校园 · 古风 · 二次元 · 玄幻 · 搞笑日常都市职场(风格冲突) · 男频战神(张力不足) · 山猎(画面单薄)200-500 元中(分镜需重画)

判断依据:题材适配度的核心是"该题材的核心爽点能否通过该类型的视觉语言完整传达"。

  • 战神题材的爽点是"逆袭反差 + 强动作",3D 漫能放大动作张力,AI 仿真人剧反而因为写实限制动作戏夸张度。
  • 情感戏的爽点是"微表情 + 眼神",只有 AI 仿真人剧能完整传达,3D 漫和 2D 漫角色表情僵硬是硬伤。
  • 萌宝题材核心是婴儿面部表情,当前 3 种类型都做不好(婴儿脸 AI 渲染普遍崩坏),要么换"萌宠"立场,要么真人演员。
💡
选型决策公式:题材核心爽点 = 视觉(动作 / 表情 / 场景) > 文本,则用 3D 漫;题材核心爽点 = 心理 / 微表情,则用 AI 仿真人剧;题材核心爽点 = 风格 / 节奏 / 反差,则用 2D 漫或 AI 仿真人剧均可。

四、海外题材转向:从甜宠到战神/复仇

2026 H1 海外短剧(ReelShort / DramaBox / ShortMax)出现明显转向:女频甜宠占比从 2025 H2 的 60%+ 下降至 2026 H1 的 35-40%,男频战神、强者回归、复仇、AI 玄幻、狼人、机甲、古装占比从 25% 上升至 45%+。Sensor Tower / AppMagic 2026 H1 估算

驱动因素(3 个)

  1. 用户付费 LTV 差异:海外男频用户单部付费意愿比女频高 40-60%(男频单部平均 LTV 25-35 美元,女频 15-22 美元),男频单部 ROI 更高,头部制作方资源倾向男频。
  2. AI 制作门槛降低:战神 / 玄幻的视觉冲击力靠 AI 大幅降低,1 部 80 集男频短剧的制作周期从 8 周缩至 2 周,头部公司可在 1 个月内上线 2-3 部,试错成本极低。
  3. 区域偏好分化:欧美主复仇/豪门/爱情;中东偏悬疑/家庭伦理;东南亚偏本土化甜宠与奇幻。同一男频题材在欧美市场表现远好于东南亚。

国内编剧能不能复用海外趋势?

能,但要本土化改编。海外男频战神多用"观众呈现",国内抖音/红果端用户更喜欢"反派呈现"(每集必有一个反派被狠狠打脸)。简单搬运会水土不服,必须重写反派动机 + 打脸节奏 + 文化梗。

⚠️
不能照搬的反派逻辑:海外男频反派往往是"强大但有原则",被反派的逻辑是"被更强的力量击败";国内男频反派往往是"恶无底线",被反派的逻辑是"恶有恶报 + 即时报应"。直接搬运海外剧本,反派没底线 + 主角讲道理 = 用户会弃剧。

五、题材饱和度判断(还能写 vs 已经写烂了)

判断一个题材"还能写"还是"已经写烂了",看 3 个数据指标 + 1 个主观判断:

指标还能写(上车)饱和(慎上车)写烂了(下车)
单部播放增量均值趋势近 3 个月稳定或上升近 3 个月下滑 30%+近 3 个月下滑 60%+
TOP10 集中度TOP10 占总流量 < 50%TOP10 占 50-70%TOP10 占 > 70%(头部吃掉所有)
新剧供给增速 vs 播放增速播放增速 > 供给增速供给增速 ≈ 播放增速供给增速 > 播放增速(内卷)
用户评论关键词新意 · 反转 · 节奏快相似 · 套路 · 看腻了全是抄 · 烂大街 · 别再写了

案例(脱敏):《XX 重生之我是千亿富豪》 题材饱和度判断

  • 8 月单部播放增量均值 180 万,7 月 320 万 → 下滑 44%,踩入"慎上车"。
  • TOP10 集中度 65%,踩入"饱和"。
  • 8 月新剧供给 8500 部,7 月 6000 部,新剧供给增 41%,但总播放增量只增 8% → 供给 > 播放,内卷。
  • 用户评论高频词:套路 / 类似 / 没有新意 → 主观判断"已经写烂了"。

判断:该题材不再上车。如果要做"重生"题材,必须找差异化角度(如《重生之我在大唐当县令》——把重生从"商战"切到"古代基层治理",完全跳出原套路)。

六、自检清单(8 项)

  • 题材核心爽点是否清楚?用 1 句话写出"这部短剧,观众看的是什么"。如果说不清,题材没定位。
  • 单部均值是否在"还能写"区间?查 DataEye ADX 最近 3 个月数据,均值连续 3 个月稳定或上升才上车。
  • TOP10 集中度是否 < 70%?高于 70% 说明头部已垄断,新剧上分账空间被压。
  • 类型(3D/仿真/2D)与题材匹配吗?查上方"AI 仿真人剧 vs 3D 漫 vs 2D 漫"表,类型不匹配会导致制作成本翻倍但效果差。
  • 目标平台与题材匹配吗?红果男频 / 抖音仿真人 / 快手乡土 / B 站创意——平台选错或差 5-10 倍。
  • 海外题材是否做过本土化?海外剧本直接搬运到国内,反派逻辑/打脸节奏/文化梗三处必改。
  • 新细分题材窗口期还在吗?查 8 月新崛起题材,3-6 个月内是窗口期;超过 6 个月饱和度上升。
  • 用户评论是否已经出现"套路" "相似"?出现即进入饱和,需要换角度或换题材。

三、AI 生成内容的著作权边界(2024-2026 司法实践)

贡献类型是否受保护判定依据
纯 prompt 一次性生成❌ 不受保护北京互联网法院"春风送来了温柔"案(2024) — 缺少人类独创性表达
AI 生成 + 用户多轮修改⚠️ 视修改幅度修改需达到"独创性表达"门槛
AI 生成 + 用户做了实质性选择和判断✅ 受保护用户对表达元素有创造性贡献
人类写大纲 + AI 补完台词✅ 大纲+台词合并整体由人类主导
AI 生成 + 人类只做了 1 处微调❌ 微调不构成独创实质性贡献门槛未达

"实质性选择和判断"边界:用户对角色设计、情节走向、关键转折有创造性贡献时,整体受保护;纯 prompt 一次性生成不受保护。

实操建议:每次 AI 生成后,人工做 3 处实质性修改(角色动机 / 转折逻辑 / 关键台词),并记录修改日志(日期/改动点/原因)。修改日志是日后维权证据。

一、Save the Cat 为什么不能直接缩放到短剧

Blake Snyder 的《Save the Cat》15 节拍为约 110 页 / 90 分钟长片设计,根本不是时长问题,而是观众心理机制不同。

维度长片(90 分钟)短剧(单集 90 秒)后果
观众耐心窗口15 分钟(可铺垫)3 秒(必出钩子)短剧无铺垫空间,开场即冲突
情节密度1 个/5 分钟1 个/15 秒短剧密度高 20 倍
角色登场节奏主角 5 分钟展示主角 3 秒内确立短剧需要"前置主角设定"
情绪切换频率中(可慢热)高(每 15 秒一个反转)短剧无"平静段落"
付费心理无(买票入场)强(每集都要"再来一集")短剧要把"再来一集"做成肌肉记忆

短剧观众心理机制 3 个不同:

  1. 付费沉浸:长片观众"被动观看",短剧观众"主动付费解锁"——后者期待"立刻爽"。
  2. 碎片时间:短剧用户常在地铁/厕所/午休时看,注意力随时会被打断,必须每 15 秒一个视觉锚点。
  3. 选择替代:用户可以在抖音刷走,你必须在 3 秒抓住——长片观众已经买票坐下了,不会走。
💡
可借用的 Save the Cat 元素:
① 15 节拍的"关系转折"概念可借用(救猫咪节拍 = 反派第一次示弱);
② "B 故事"概念可借用(角色情感支线);
③ "Finale"概念可借用(全剧大高潮)。
不可直接借用:铺垫节奏、平静段落、长片式角色展开。

二、红果三级卡点(10-15/28-32/55-58 集)设计依据

红果 IAP 模式下,用户付费解锁下一集。付费墙卡点 = 用户决策点,卡得太早用户弃剧,卡得太晚用户已弃。

卡点位置(集)设计依据数据支撑
第一道墙10-15用户已看完 10+ 集,建立情感投入,但剧情刚到第一波高潮前 0.5 秒红果付费用户平均付费时间在 12-13 集
第二道墙28-32用户已付费 1 次,有付费意愿;剧情在第二波大冲突后,主角即将反扑前 0.5 秒付费 2 次的用户占总付费用户 60%+
第三道墙55-58用户已付费 2 次,深度投入;剧情在最终 Boss 战前最后一刻完播率与第三道墙位置强相关

付费墙三法则(v8.0 + short-drama-factory SKILL.md 综合):

  1. 前置蓄水:付费墙前 3-5 集必须密集爆爽点,让用户觉得"不付费对不起这 10 集"。
  2. 断在反击前 0.5 秒:剧情推到"主角即将反扑"但还没反扑的瞬间切断,用户为"看结果"付费。
  3. 付费后即时兑现:付费后第一集必须立刻完成之前的反扑,不能拖。如果拖,完播率掉 30%+。
⚠️
不要断在钩子处:很多新编剧会"在钩子最强处断章",但用户的付费心理是"我要看结果"而非"我要知道答案"。结果导向的断章比悬念导向的断章转化率高 40%+。

三、单集节奏公式(两种循环配合)

循环类型位置时长占比作用

压力 → 应对 → 转折每 15 秒一个微循环15 秒控制单场戏的"递进 - 爆发"

两者关系:外层是"钩子→冲突→爽点→钩子",内层嵌套多个"压力→应对→转折"微循环。一个 90 秒单集 = 1 个外循环 + 5-6 个内循环。

  • 15-30 秒:第一个微循环"压力 → 应对"
  • 30-45 秒:第二个微循环"压力 → 转折" (爽点 1)
  • 45-60 秒:第三个微循环(爽点 2)
  • 60-75 秒:反派压制 / 升级冲突
  • 75-90 秒:小爽点 + 下集钩子

一、AI 播音腔的 8 个可识别特征

AI 生成的剧本最难处理的不是"用错词",而是"播音腔"——看起来文字通顺,但读起来像新闻稿而非人物说话。短剧观众对"播音腔"的容忍度比长片低 10 倍,因为 90 秒内必须让人信。

特征AI 播音腔表现改后(短剧写法)出现频率
情感形容词堆砌"他眼中满是震惊与愤怒""他嘴唇抖了一下,手攥成拳"极高
书面词代替口语"你简直岂有此理""你有病吧?"极高
对话平均长度过长单句对话 30-50 字单句对话 8-15 字高
逻辑链完整但无冲突"我想了想,然后说"直接进入冲突,不解释中
角色性格趋同所有反派说话一个腔反派各有口头禅 / 行为习惯高
缺少具体指代"某个公司 / 某个人 / 某个地方""南城科技园 B 栋 / 王总监 / 庆丰路"极高
过度铺陈环境"夜幕降临,华灯初上……"直接给画面,文字不写中
对话像旁白"我永远也不会忘记这一天""今天这账,我记下了"极高
⚠️
为什么播音腔会让观众弃剧?短剧观众是"代偿式观看"——他们看短剧就是为了"在 90 秒里代入主角碾压反派"。一旦文字有播音腔,观众的代入感被打断,会出现"我好像在看新闻"的剥离感,3 秒内划走。短剧写作者的终极目标:让观众忘了这是"剧本",以为是"自己脑子里发生的事"。

二、剧本医生 5 大修改动作

改稿不是"改文字",而是5 个动作的循环。每个动作都对应一个具体问题,不能跳过。

动作目标问题操作步骤耗时占比
① 砍事件这一集是不是只讲一件事?砍掉所有"非主线事件",保留主线 + 1 个支线10%
② 砍对话每句对话是不是只有 1 个意思?30 字以上对话必有冗余,砍到 15 字内30%
③ 砍形容词每 5 行有没有 1 个具体动作?把"震惊/愤怒/温柔/冷漠"换成具体动作25%
④ 加具体指代每集有没有 5 个真实细节?人名/地名/品牌/数量词/数字,缺一补一20%
⑤ 加潜台词每集有没有 2 处"言外之意"?把直白对话改成"反话 / 不说完的话 / 反讽"15%

5 动作循环执行示例(90 秒单集改稿):

  1. 砍事件:原剧本 5 个事件 → 砍到 3 个(开场冲突 + 主体反扑 + 结尾钩子)。
  2. 砍对话:原对话 12 句 → 砍到 7 句,每句不超过 15 字。
  3. 砍形容词:把"他愤怒地说" → "他咬了咬牙"。
  4. 加具体指代:"某个公司" → "南城科技园 B 栋"; "几十万的合同" → "38 万的订单"。
  5. 加潜台词:"你这个骗子" → "哟,王总这是又换办公室了?"(反讽 + 不撕破脸)。
💡
改稿的"3 遍原则":
第一遍:砍(减法,砍掉 30% 内容);
第二遍:换(替换形容词为动作);
第三遍:加(加具体细节 + 潜台词)。
不要"加法改稿":不要在原剧本上"加东西",那是加戏而非改稿。

三、三视角审稿(用户 / 反派 / 旁观者)

改稿的核心难点是"作者视角偏差"——作者已经知道结局,无法代入第一次看的观众。3 视角审稿是修正这种偏差的标准流程。

视角审稿问题审稿重点出现典型问题
用户视角(主角代入)这一集是不是够"爽"?看 90 秒有没有 3 个爽点 + 1 个反转"铺垫太长 / 爽点不集中 / 反转太弱"
反派视角(逻辑检验)反派的行为合不合理?反派的每一步行动有没有动机支撑"反派太蠢 / 反派太无敌 / 反派无底线"
旁观者视角(沉浸检验)观众会不会"出戏"?看有没有"作者跳出来说话"的痕迹"旁白太多 / 心理描写过多 / 解释太清楚"

用户视角审稿 3 检查

  • 前 3 秒是否抓住我?如果你是用户,前 3 秒你会不会划走?如果会,钩子失败。
  • 每 15 秒我有没有"哦"一下?微循环是不是够密?
  • 看完这集我想不想看下一集?结尾钩子是否到位?

反派视角审稿 3 检查

  • 反派为什么这样做?每个反派动作都要有"利益动机"或"性格动机",不能"为反而反"。
  • 反派有没有一次"赢"?如果反派全剧 100% 输,观众会无聊——反派至少要"赢 3 次输 7 次"。
  • 反派被反派时我爽不爽?如果反派被反派时观众没爽感,打脸节奏错了。

旁观者视角审稿 3 检查

合同谈判黄金法则:永远分项谈,不要"打包谈"。打包谈=对方在弱势条款上让步,强势条款上反扑。分项谈=每个条款独立议价,对方无法"以强带弱"。

五、自检清单(8 项)

  • 授权标的精确?具体书名 + 作者 + 完结状态,不能写"等作品"。
  • 授权形式分项?短剧 / 漫剧 / 海外 必须分项写,不能"全媒体"打包。
  • 授权期限 ≤ 3 年?超过 3 年的合同慎签,IP 价值下降后被锁。
  • AI 训练有限制?必须写"仅限本剧改编,不可训练通用模型"。
  • 真人脸授权单独?即使主合同签了,真人脸使用必须另行书面授权。
  • 独家性?对方不可同时授权他人,二次授权需我方同意。
  • 分账透明?独立结算 + 季度审计权,不接受"代为分账"。
  • 违约金 ≥ 30%?违约金低于 20% 拒签,违约成本必须高。

一、改编 7 步 SOP(标准流程)

从拿到一本 5000-30000 字短篇小说,到产出 80 集 / 每集 90 秒剧本,标准 7 步流程。每步对应一个产出物 + 一个卡点。

总周期:21-30 天 / 部(标准 80 集剧本)。如压缩到 14 天,需要砍掉 ② ⑤ ⑥ 三步,风险极高。

7 步常见错误(按出现频率排序)

  1. 跳过 5 维评分直接改编:60% 新手栽在这步,选到"看着不错但综合分 < 65"的书。
  2. 付费墙位置拍脑袋:50% 编剧不按 10-15/28-32/55-58 设计,导致转化率掉 40%+。
  3. 每集塞 5+ 事件:90 秒内塞太多事件,观众"看不懂 = 弃剧"。
  4. 直接用 AI 稿不"剧本医生":AI 稿播音腔残留,完播率比人工改稿低 30-50%。
  5. 相似度查重走过场:不查结构相似度,被告"实质性相似"赔款 50-200 万。
  6. 角色人设不一致:同一角色在第 5 集"冷静",第 30 集"冲动",观众弃剧。
  7. 结尾钩子不承接付费:结尾钩子弱 → 用户不为下一集付费 → 完播率掉。

二、心理活动 → 动作/台词的转化公式

短剧最大的转化难题是"把心理活动变成画面"。小说可以写 3 页心理活动,短剧只能 3 秒内完成。

心理活动(小说原句)短剧动作转化短剧台词转化
他感到震惊,无法相信眼前的一切后退一步,撞到椅子 / 手中的文件掉到地上"你……你说什么?"(语气 + 短句)
她感到愤怒,想要报复攥紧拳头 / 摔杯子 / 切镜头到特写眼神"这笔账,我记下了。"
他内心愧疚,想要道歉低头 / 抬手又放下 / 走到门口停下"……对不起。"(停顿 + 短句)
她感到心动,想靠近无意识地抬手 / 整理头发 / 眼神躲闪(不说话,只一个动作)
他感到恐惧,想要逃跑后退 / 跌坐 / 眼神左右扫"别过来!"
她内心挣扎,做不了决定来回踱步 / 坐下又站起 / 攥紧手机"……我该怎么办?"

转化核心原则 3 条

  • 具体化原则:心理活动 → 具体可拍动作(撞椅子 / 摔杯子),不要"表情凝重"。
  • 反差化原则:心理活动 ≠ 表面动作(心里愤怒,表面冷静说话 → 高级感)。
  • 节奏化原则:心理活动 → 0.5-3 秒动作 + 短句台词(单句 ≤ 15 字)。

实战案例(脱敏):某战神小说第 1 集开头

原小说(心理描写):

相似度检查 · 反推查重

10% 执行标准 · 3 档改写 · 案例

一、相似度 3 维度:文字 / 结构 / 角色

短剧改编的相似度检查 ≠ 单纯"文字查重"。短剧被告"实质性相似",通常是结构相似 + 角色相似,而非"文字相似"。

维度检查内容工具 / 方法阈值重要性
① 文字相似度逐字句查重,改写后剩余重复率PaperPass / 知网 / 万方 / 蚁坊等≤ 10%★★
② 结构相似度主线 / 反转 / 高潮节点是否一致人工对照 + 反推 SOP≤ 30%★★★★★
③ 角色相似度主角人设 / 反派动机 / 配角关系角色卡对照 + 关系图谱≤ 40%★★★★

为什么结构 / 角色比文字更重要?

司法实践中,法院判定"实质性相似"主要看结构 + 角色。即使文字完全不同,如果主线反转高潮位一致 / 主角人设反派动机一致 / 配角关系一致,仍可能被判定"实质性相似"。

  • 案例(2024 短剧判例):某改编方把原作文字改了 70%,但主线结构、3 个关键反转、主角"重生穿越"设定与原作高度相似,被判"实质性相似",赔偿 80 万 + 作品下架。
  • 教训:只查文字相似度 = 自欺欺人。结构 + 角色 才是法律风险核心。

二、10% 执行标准(平台 + 法律双重线)

短剧相似度的执行标准 = 10%。这个数字来自两个维度:

维度来源阈值超出后果
平台标准红果 / 抖音 / 快手原创审核文字 ≤ 10%超出直接拒上 / 下架
法律标准司法判例"实质性相似"标准结构 + 角色 ≤ 30-40%超出可能被告
行业自律短剧头部制作方共识综合 ≤ 15%超出影响后续授权

执行原则:

  • 文字相似度 ≤ 10%(平台硬线)
  • 结构相似度 ≤ 30%(法律警戒线)
  • 角色相似度 ≤ 40%(法律警戒线)
  • 3 维度任一超出,必须返工
⚠️
为什么是 10%?低于 10% 平台审核 + 法律风险双重安全。10%-15% 平台可能通过但法律风险高。15%-30% 平台通过但有法律风险。30% 以上基本会被告 + 平台下架。结论:目标 ≤ 10%,可接受 ≤ 15%,15% 以上必须改。

三、3 档改写对照(从高到低)

档位目标相似度改写强度适用场景风险
A 档(微改)15-30%换词 + 调语序原作无授权风险(同人练习)不可商用,被告必败
B 档(中改)10-15%重构情节 + 换视角 + 调反转位置已获授权 + 改编方有充足法务可商用,有法律风险
C 档(深改)≤ 10%重新立意 + 重组人物关系 + 调主线结构已获授权 + 改编方需长线发展零风险,推荐

A 档(微改)案例对照

原作:林北辰站在南山科技园门口,被前台小姐以"先生您找谁"为由拒绝入内。
A 档改写:林北辰站在南山科技园门口,前台小姐微笑着问"先生您找谁",林北辰被拦在门外。
相似度:文字 25% / 结构 90% / 角色 95% → 不可商用。

B 档(中改)案例对照

原作:同上
B 档改写:林北辰从黑色商务车下来,直接走进南山科技园大堂,绕过前台,按下顶层电梯按钮。
相似度:文字 12% / 结构 60%(场景转换 + 入场方式变化) / 角色 70%(主角动机一致但反派出场顺序变) → 可商用,有法律风险。

C 档(深改)案例对照

C 档改写:林北辰身份改为"被陷害离职的核心工程师",王总改为"竞争对手公司新任 CEO",场景改为科技园对面酒店咖啡厅,主角带合同而非复仇。

四、反推查重 SOP(从原作反推查重)

拿到授权书后,改编前必须做"反推查重":从原作反推"哪些会被被告实质性相似",然后针对性改写。

步骤操作产出物工具
① 反派动机反推原作反派的"动机 + 手段 + 反扑节点"反派动机清单人工 + AI 辅助
② 主角金手指反推原作主角的"金手指类型 + 升级节奏"金手指清单人工
③ 关键反转反推原作 3-5 个关键反转的"铺垫 + 爆发 + 后续影响"反转节点表人工
④ 名场面反推原作最具传播力的"名场面 / 金句"名场面清单人工 + 弹幕数据
⑤ 角色关系反推原作主角 / 反派 / 配角的"关系网 + 关系变化"关系图谱人工 + AI 辅助

反推后针对性改写

  • 反派动机改 50%:原作反派"嫉妒主角" → 改编反派"被主角父亲陷害过" → 动机不同但戏剧张力相似。
  • 金手指改类型:原作"系统流" → 改编"重生流" → 类型完全不同。
  • 反转调位置:原作第 30 集的反转 → 改编调到第 20 集 + 第 40 集。
  • 名场面必改:原作最具传播力的 3 个名场面必须重写。
  • 角色关系重组:原作"兄弟反目" → 改编"师徒反目",关系网重组。
💡
反推查重的核心原则:不是"避开原作",而是"从原作反推哪些元素被告风险高,改这些元素"。直接"完全避开原作"会导致"原作味儿没了,观众不买账"。正确做法是"保留原作精神 + 改高风险元素"。
