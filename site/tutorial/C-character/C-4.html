C-4 · FaceID 锁脸

1. 什么是 FaceID

FaceID = 用 InsightFace 模型提取人脸 512 维向量,注入 AI 出图,锁住"脸"。比 IP-Adapter 更精准,但配置要求高(需 InsightFace 安装)。

📦

本节讲原理与调试 · FaceID 安装 / 工作流 / 节点连接全部集中在 ComfyUI 专题。

2. FaceID vs IP-Adapter

对比FaceIDIP-Adapter
精度⭐⭐⭐⭐⭐ 锁脸⭐⭐⭐⭐
安装复杂(需 InsightFace)简单
显存额外 1GB额外 1.5GB
速度35s/张30s/张
学员用锁脸要求高的 30%一般需求 90%

3. Weight 调试 SOP(通用方法论)

  1. 固定 Seed
  2. 出 3 张对照:Weight = 0.6 / 0.75 / 0.85
  3. 0.6 脸松但姿势自由
  4. 0.75 平衡(学员首选)
  5. 0.85 锁脸最强但姿势受限
  6. 记录最优值
💡

📌 玉哥金句:Weight 0.7-0.85 是 FaceID 锁脸甜区

4. 常见报错

❌

"InsightFace 模型找不到" · 检查 InsightFace 模型路径(参考 ComfyUI 专题文档)

❌

"FaceID 模型与基础模型不匹配" · SDXL 必须用 sdxl_faceid,SD1.5 用 sd15_faceid

5. 学完这节能做啥

  • 懂 FaceID 锁脸原理
  • 会调试 Weight
  • 知道 FaceID vs IP-Adapter 区别
  • 能找到 ComfyUI 专题学装法

6. 小结

📢

📢 小结:
1. FaceID 锁脸最强 · 但配置复杂
2. 一般需求用 IP-Adapter · 简单够用
3. 锁脸要求高的用 FaceID
4. Weight 0.75 · 学员首选
5. 装法见 ComfyUI 专题
