C-8 · 侧面和三视图

1. 为什么 3 视图必要

漫剧镜头有正面 / 侧面 / 背面(转身)。只 1 张正面 = AI 出侧脸/背影时漂移。3 视图 = IP-Adapter 多参考 = 80 集侧脸/背影一致。

2. character sheet 一键出法

工具怎么做
节点 workflow搜 "character sheet workflow"
prompt 关键词character sheet, multiple views, front side back
出图结果1 张图含正面/侧面/背面

3. 手动 3 步

  1. 正面图(已出,见 C-7)
  2. 侧面图:加 "side view, profile view, looking right"
  3. 背面图:加 "back view, from behind, looking away"

📌 玉哥技巧:固定 Seed,3 张角色一致

4. 三视图 prompt 范本

# 主角三视图(1 张含 3 视角)
character reference sheet, multiple views of the same man,
front view, side view (looking right), back view,
30 year old Asian man with square face, short black hair,
white shirt and black pants,
white background, even lighting, full body,
9:16 aspect ratio

5. IP-Adapter 多参考用法

3 视图都放进 IP-Adapter:

  1. Load Reference × 3(正/侧/背)
  2. 合并到 1 个 IPAdapter Batch
  3. Weight = 0.7
  4. 新镜头 prompt 加 "side view" 时,AI 自动调侧面参考

6. 学完这能做啥

  • 能出 3 视图
  • 会用 character sheet workflow
  • 能 IP-Adapter 多参考
