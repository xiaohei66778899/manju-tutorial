TOP画风原因

3. 选画风决策树

玉哥决策

🌳 你是哪种题材?

  • 战神/龙王/闪婚 → 写实
  • 校园/甜宠 → 二次元
  • 玄幻/仙侠 → 国风
  • 重生年代(穿越到 1980) → 写实
  • 儿童向 → 3D / 二次元

4. 画风混用(高级)

学员 5% 作品混用画风(主写实 + 回忆片段二次元):

  • 主剧情 = 写实
  • 回忆/前世 = 二次元(区分)
  • 梦境 = 国风

📌 混用能区分场景,但 80% 学员用统一画风(更稳)
