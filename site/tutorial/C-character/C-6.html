C-6 · 固定服装和配饰

1. 学员主服标准

角色主服颜色辨识度
主角(战神)白衬衫 + 黑西裤黑 + 白⭐⭐⭐⭐⭐
女主白裙白⭐⭐⭐⭐⭐
兄弟迷彩服绿 + 棕⭐⭐⭐⭐
秘书黑色西装黑⭐⭐⭐⭐
反派黑色中山装黑⭐⭐⭐⭐⭐

2. 主服 + 变体公式

玉哥 SOP

👔 1 主服 + 2 变体

主角服装:
  主服(60% 集数): 白衬衫 + 黑西裤
  变体 1(25%): 黑色 T 恤 + 牛仔裤(休闲)
  变体 2(15%): 战损外套 + 战损衣(决战)

女主服装:
  主服(70%): 白裙
  变体 1(20%): 婚礼白纱
  变体 2(10%): 战损

📌 玉哥金句:主服 ≥ 60%(否则漂移)。变体 ≤ 40%

3. 配饰设计

角色标志性配饰
龙王婚戒 + 黑色手表
女主珍珠耳环
反派金表 + 翡翠戒指
秘书黑框眼镜
兄弟军牌项链

4. prompt 锁服装

主体服装:白色衬衫 + 黑色西裤 + 黑色皮带
  + 黑色皮鞋 + 银色手表
  + 左手无名指银色婚戒

负面提示词:
  casual clothes, sportswear, jacket, hoodie,
  colorful clothing, bright colored shirt

5. 战损服(决战用)

第 40-60 集决战可以用战损:

战损描述:
  torn white shirt with blood stains,
  black pants with dust and scratches,
  messy hair, intense expression

6. 学完这节能做啥

  • 能设计主服 + 变体
  • 能写锁服装 prompt
  • 能设计标志性配饰

7. 玉哥说

📢

📢 玉哥说:
1. 主服 ≥ 60%(玉哥标准)
2. 1 主服 + 2 变体(最多)
3. 标志性配饰(辨识度)
4. 战损服决战用(15% 集数)
5. 服装 = 辨识度核心
