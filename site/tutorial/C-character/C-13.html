C-13 · 用 IP-Adapter

1. IP-Adapter 4 模型

模型用途
ip-adapter-plus通用,SD1.5
ip-adapter-plus-face锁脸专用,SD1.5
ip-adapter-plus_sdxlSDXL 通用
ip-adapter-plus-face_sdxlSDXL 锁脸,学员首选

2. IP-Adapter 5 步 SOP(通用方法)

  1. 加载 1 张主角参考图
  2. 选择模型(SDXL 用 plus-face_sdxl)
  3. 应用 IP-Adapter 节点
  4. 连到出图采样器
  5. 设 Weight = 0.7
📦

具体节点连接 / 模型路径 · 见 ComfyUI 专题

3. 实战调试

  1. 固定 Seed,出 3 张对照
  2. Weight 0.4 / 0.6 / 0.8
  3. 挑 1 张脸最像的
  4. 记录 Weight 值

4. 多张参考(高级)

  1. 加载 N 张参考图(主图 + 表情 + 侧脸)
  2. 合并到批量节点
  3. 权重平均(主图 1.0 + 其他 0.8)
  4. → 采样器出图

📌 多参考混合 · 学员 50% 用"主图 + 表情"组合,效果更稳

5. 学完这能做啥

  • 懂 IP-Adapter 4 个模型
  • 会调试 Weight
  • 会用多张参考
  • 能找到 ComfyUI 专题学装法

6. 小结

📢

📢 小结:
1. IP-Adapter 90% 学员首选
2. SDXL 用 plus-face_sdxl · 锁脸最强
3. Weight 0.6-0.7 · 玉哥甜区
4. 装法见 ComfyUI 专题
