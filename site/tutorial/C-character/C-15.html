C-15 · 用角色 LoRA

1. 什么时候训 LoRA

情况建议
主角出场 > 50 镜头✅ 训 LoRA
配角/工具人IP-Adapter
第 1 部试水❌ 不训
第 5 部开始✅ 训

2. 训 LoRA 流程 5 步

  1. 准备 20-50 张主角参考图(多角度)
  2. 打标签(用 BLIP / WD Tagger)
  3. 选训练器(kohya-ss / ai-toolkit)
  4. 设置参数(步数 / LR / Rank)
  5. 训 30 分钟 - 2 小时

3. 学员参数

参数玉哥标准
训练步数1500-3000
学习率(LR)1e-4
Rank16 / 32
分辨率512 或 1024
重复10
Batch Size1-2

4. LoRA 调权重

权重效果
0.4轻微角色感
0.6-0.8✅ 玉哥甜区
0.9+过度,衣服变

5. 常见问题

❌

触发后脸不像 · 数据身份信号弱 / 权重低 → 增加图片数量,提高权重

❌

姿势难以改变 · 过拟合 → 降低权重

⚠️

只记住某套服装 · 身份与服装未解耦 → 减少服装变化数据

6. 学完这能做啥

  • 能训 LoRA
  • 能调权重
  • 能识别过拟合
