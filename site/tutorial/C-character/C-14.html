C-14 · 用 FaceID

1. FaceID 5 大优势

  1. 512 维人脸向量,精度高
  2. 不被发型/服装干扰
  3. 多角度都能锁(正/侧/仰/俯)
  4. 适合特写镜头
  5. 与 IP-Adapter 兼容

2. 装 FaceID 4 步

  1. 节点管理器 → 装 Impact-Pack 节点
  2. 下载 insightface buffalo_l 模型
  3. 下载 ip-adapter-faceid-plusv2_sdxl.bin
  4. 放进对应文件夹

3. 节点 SOP

1. Load Reference(主角脸图)
2. IPAdapter FaceID 节点
3. 设置 Weight = 0.75
4. End At = 0.8
5. → KSampler

4. 调试 3 张对照

Weight效果
0.6脸略松
0.75✅ 平衡
0.9脸极锁,姿势受限

5. 与 IP-Adapter 配合

学员 20% FaceID + IP-Adapter 混合:

  • FaceID:锁脸
  • IP-Adapter:锁服装 + 风格

6. 学完这能做啥

  • 能装 FaceID
  • 能调 Weight
  • 能混合 IP-Adapter
