C-16 · 两个角色串脸怎么办

1. 串脸 3 大表现

  • 主角脸变反派脸
  • 两角色都是同一张脸
  • 主角消失,只看见反派

2. 5 大原因

  1. 用单 IP-Adapter 出多人
  2. 没分区域 Mask
  3. 两个角色太相似(脸型/服装)
  4. 参考图权重过低
  5. prompt 没说"两个不同男人"

3. 玉哥 4 步修法

  1. 分区域 Mask:左右各 1 个 Mask,每个区域独立 IP-Adapter
  2. 加"两个不同男人"到 prompt
  3. 用 "on the left / on the right" 区分
  4. 避免相似服装:主角白衬衫,反派黑西服
📦

具体节点实现(IPAdapter Regional / Mask blur) · 见 ComfyUI 专题

4. 兜底:单角色 + PS 合成

15% 学员用兜底法:

  1. 主角单独出 1 张(无反派)
  2. 反派单独出 1 张(无主角)
  3. PS 合成 2 张
  4. 调色统一

5. 学员验证

  • 多人镜头串脸率从 30% → 5%(用区域 Mask)
  • PS 合成耗时 ×3(不推荐)

6. 学完这能做啥

  • 能识别串脸
  • 能分区域 Mask
  • 能用 PS 兜底

7. 小结

📢

📢 小结:
1. 串脸 = 多人最大坑
2. 分区域 Mask · 80% 学员用
3. "两个不同男人" · 加 prompt
4. PS 合成 · 兜底但费时
