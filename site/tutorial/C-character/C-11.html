C-11 · 角色一致性(玉哥口吻)

1. 为什么不用"百分比"

"这张图角色一致率 90%" — 错的!"一致率" 没有数学定义。AI 角色一致性 = 多维度,不是单一指标。

2. 玉哥 8 项硬指标

#指标怎么判断
1面部身份五官结构像不像
2发型发色/长度/刘海
3年龄看起来是否同龄
4体型高矮胖瘦
5服装主色 + 款式
6配饰眼镜/项链/武器
7画风写实/日漫/3D 一致
8多人不串脸A 像 A,B 像 B

3. 玉哥验收 SOP

  1. 把主角 8 个维度的参考图拼成 1 张大图
  2. 新图出来后,逐项打勾
  3. 8 项全过 = 一致
  4. 不打勾直接过 = 100% 翻车

📌 玉哥金句:8 项全过 = 一致。不打勾 = 100% 翻车

4. 8 项权重(实战)

指标权重原因
面部身份40%最重要
发型20%第 2 易漂
服装15%辨识度
年龄10%易漂
体型5%稳定
配饰5%稳定
画风3%稳定
多人不串脸2%最难

5. 实战工具

学员工具:

  • IP-Adapter:解决 1-4 项
  • FaceID:专攻面部身份
  • LoRA:全套锁定
  • 多 IP-Adapter + Mask:多人不串

6. 学完这能做啥

  • 能用 8 项硬指标
  • 能逐项打勾验收
  • 能避免"一致率"陷阱
