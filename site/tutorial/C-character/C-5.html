C-5 · 固定发型和年龄

1. AI 漂移的 5 大原因

  1. 发型:短发 → 长发 / 黑 → 棕
  2. 年龄:30 → 25 或 35
  3. 脸型:国字 → 瓜子
  4. 身高:180 → 175(不变,但 AI 自由发挥)
  5. 服装:白衬衫 → 黑衬衫

2. 锁发型 4 法

方法效果学员用
1. IP-Adapter⭐⭐⭐⭐✅ 90%
2. FaceID⭐⭐⭐⭐⭐✅ 30%
3. 角色 LoRA⭐⭐⭐⭐⭐✅ 主力角色
4. 多次 prompt 强调⭐⭐应急

3. prompt 锁发型模板

主体:30 岁亚洲男性
发型:黑色短发,偏分,刘海 3cm
年龄:30 岁(不要看起来像 25 或 35)
面部:无胡须,无皱纹
服装:白衬衫

📌 玉哥技巧:prompt 里 "30 岁"出现 2 次(主体 + 年龄),AI 更难漂移

4. 玉哥负面 prompt

负面提示词(锁发型年龄):
long hair, blonde hair, brown hair, white hair, bald,
beard, mustache, wrinkles, aged face,
old looking, young looking, child face

📌 5 大类否定:长 / 棕 / 白 / 秃 / 胡须 / 皱纹 / 老 / 幼

5. 验证 SOP

  1. 出 10 张对照图
  2. 检查每张主角的发型
  3. 10 张中至少 8 张应该是"黑色短发"
  4. <6 张 = 调整 prompt / 用 IP-Adapter

6. 学完这节能做啥

  • 能锁发型年龄
  • 能写 prompt + 负面 prompt
  • 能验证一致性

7. 玉哥说

📢

📢 玉哥说:
1. 发型年龄最易漂移 · 80 集必锁
2. prompt 双写"30 岁" · 强调 2 次
3. 负面词 5 大类 · 长/棕/白/秃/胡须
4. 10 张验证 · ≥8 张一致 = 锁定
