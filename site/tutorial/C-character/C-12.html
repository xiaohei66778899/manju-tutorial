C-12 · 用参考图保持一致

1. 参考图 4 类

类型用途数量
正面图基础参考1 张
侧面图侧脸镜头1 张
背面图背影镜头1 张
表情图喜怒哀乐6 张

2. Weight 调试

Weight效果
0.4脸松,姿势自由
0.6-0.7✅ 玉哥甜区
0.85+脸锁死,姿势受限

3. Start At / End At

控制 IP-Adapter 在采样过程中的介入时机:

  • Start 0.0:从一开始介入
  • End 0.8:到 80% 步数停止
  • End 提前(0.6) = 给 AI 更多自由发挥(构图更活)
  • End 推后(0.9) = 锁脸更强

4. 多参考图混合

# 混合权重(各 50%)
正面参考 × 1 (weight 1.0)
侧面参考 × 1 (weight 0.8)
→ 高级混合节点(权重平均)

📌 学员 50% 用"主图 + 表情"混合,效果更稳

5. 学完这能做啥

  • 能用 4 类参考图
  • 能调 Weight / Start / End
  • 能混合多参考图

6. 小结

3. End 0.8 · 给 AI 自由发挥
4. 多参考混合 · 主图 + 表情 = 学员 50%
