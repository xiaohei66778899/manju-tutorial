I-8 · 错误关键词速查

1. model not found

报错:"model not found [name] undefined model"
原因:目录错 / 文件没下载完 / 格式不支持
修法:检查 models 目录(checkpoints / diffusion_models / vae / text_encoders / clip_vision / loras)

2. shape mismatch

报错:"shape mismatch size mismatch mat1 mat2 tensor"
原因:混用了不同模型家族的 VAE / ControlNet / LoRA / CLIP / IP-Adapter
修法:逐个替换,核对每个权重的基础模型与架构

3. prompt ignored

报错:"提示词不生效 prompt ignored CLIP"
原因:文本编码器错 / 模型不依赖负面提示 / 参考条件压制文本
修法:暂时移除 IP-Adapter/ControlNet,固定 Seed 测试

4. CUDA out of memory

报错:"CUDA out of memory tried to allocate X GiB"
原因:显存不足
修法:降分辨率 / 用 FP8 / 用 --lowvram 启动 / 减小 batch

5. node not found

报错:"Cannot find node [NodeName]"
原因:节点包没装 / Manager 没装
修法:ComfyUI-Manager → Install Missing Custom Nodes

6. workflow error

报错:"Workflow contains unexpected node types"
原因:工作流版本不对 / 缺节点
修法:Manager → Install Missing Custom Nodes 或换回旧版本

7. connection lost

报错:"Connection lost / WebSocket disconnected"
原因:浏览器关闭 / 服务器崩溃
修法:重启 ComfyUI,重新打开

8. VAE error

报错:"VAE decode error latent shape mismatch"
原因:VAE 与模型不匹配
修法:用 SDXL 配 sdxl_vae.safetensors

9. LoRA not loaded

报错:"LoraLoader not applied / strength wrong"
原因:LoRA 路径错 / 强度 0
修法:检查路径,设 strength 0.6-0.8

10. sampling stuck

报错:"Sampling 卡住 / 永远 0%"
原因:内存不足 / 模型加载中
修法:重启,检查 RAM / 模型完整性
