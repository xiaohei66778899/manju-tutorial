D-8 · 动作设计

2. 避免的 5 大动作

  1. 武术(拳 / 腿 / 翻滚)— 难画
  2. 舞蹈(复杂姿势)— 难画
  3. 多手指互动(弹琴 / 打字)— 手指畸形
  4. 拥抱 / 亲吻(两人融合)— 翻车
  5. 跳跃 / 翻滚(动态)— 难画

3. 玉哥动作设计 4 原则

  1. 简单胜复杂:站 / 坐 / 走 = 90% 镜头
  2. 分镜拆细:复杂动作拆 2-3 个镜头
  3. 手部特写:手部动作只 1 个特写
  4. 实战用慢镜头:打斗用慢动作镜头

4. 动作 + 镜头组合

# 龙王拍桌子
镜 1: 中景 - 龙王怒视(3 秒)
镜 2: 特写 - 手拍桌子(2 秒)
镜 3: 近景 - 王总震惊(2 秒)
= 3 镜头描述 1 个动作

5. 学完这能做啥

  • 能避坑复杂动作
  • 能拆动作
  • 能用简单动作
