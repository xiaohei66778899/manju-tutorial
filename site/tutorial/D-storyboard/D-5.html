D-5 · 正面/侧面/俯拍/仰拍

1. 6 大镜头角度

角度AI prompt情绪
正面front view / face on中性 / 直接
侧面side view / profile神秘 / 紧张
背面back view / from behind未知 / 即将揭晓
俯拍top-down / bird's eye view / overhead shot渺小 / 上帝视角
仰拍low angle / upward view / looking up强大 / 威严
斜角high angle / dutch angle / tilted紧张 / 不安

2. 玉哥 5 大经典用法

  1. 主角登场:仰拍(显得强大)
  2. 反派被羞辱:俯拍(显得渺小)
  3. 悬念:背面(即将揭晓)
  4. 紧张:斜角(不稳)
  5. 日常对话:正面或侧面

3. AI prompt 翻译

# 主角登场(仰拍)
low angle shot, looking up at the man,
heroic pose, dramatic lighting,
9:16 aspect ratio

# 反派渺小(俯拍)
high angle shot, looking down at the fat man,
vulnerable posture, harsh shadow,
9:16 aspect ratio

4. 角度 + 景别组合

组合效果
仰拍 + 中景主角强大
俯拍 + 特写反派被打
正面 + 近景对话高潮
背面 + 中景即将揭晓
斜角 + 特写紧张情绪
