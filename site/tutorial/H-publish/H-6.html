H-6 · 选择发布平台(4 平台对比)

1. 学员小张的"发错平台"血泪

学员实操 · 玉哥整理

👨‍💻 小张 · 2026 年 7 月 · 《龙王归来》80 集

小张做完 80 集,先发抖音:

  • 播放量:总 120 万
  • 收益:¥3,500(平台激励,按播放分成)
  • 完播率:42%

玉哥 review 后让他同时发红果:

  • 红果分账:¥18,000(IAA 广告分成 + IAP 付费分账)
  • 完播率:68%

同一内容,抖音 ¥3,500 vs 红果 ¥18,000 = 5 倍差距。平台选错 = 损失 5 倍收益。

📌 玉哥数据:漫剧 TOP 创作者 80% 同时发 3+ 平台。只发 1 个 = 浪费 70% 流量。

3. 平台 1 · 抖音(流量最大)

玉哥平台分析

📱 抖音 · 流量之王

用户画像:

  • 7 亿+ DAU(日活)
  • 25-45 岁主力(60%)
  • 一二线城市 50% / 下沉 50%
  • 爆款 24 小时可达 1000 万播放

收益模式:

  • 广告分成(CPM 约 ¥10-30)
  • 星图(品牌植入)
  • 带货(剧情衍生品)
  • 短剧分账:¥1-3/万播放

内容偏好:

  • 战神 / 龙王 / 闪婚 / 重生 = TOP 4 题材
  • 节奏快(开场 3 秒钩子)
  • 反转密集(每集 1 个爽点)
  • 90 秒以内单集最佳

📌 玉哥经验:抖音 = 流量首选。先发抖音测试爆款公式,再用同一公式发其他平台。

4. 平台 2 · 红果短剧(收益最高)

玉哥平台分析

💰 红果 · 漫剧最赚钱

用户画像:

  • 2 亿+ 月活
  • 30-55 岁主力(70%)
  • 下沉市场为主(三四线 + 县城)
  • 付费意愿最强(愿为全集解锁付 ¥10-30)

收益模式:

  • IAA(广告分账):¥30-80/CPM,千次播放 ¥30-80
  • IAP(付费分账):用户付费解锁全集,创作者拿 50-70% 分成
  • 学员 80 集均价:¥10,000-50,000

内容偏好:

  • 战神 / 闪婚 / 重生 / 逆袭 = TOP 4
  • 长剧更值钱(80-100 集比 30 集收益高 3 倍)
  • "虐恋 + 复仇"高 ARPU(每用户付费)

📌 玉哥金句:红果 = 漫剧收益之王。学员 90% 主战场。抖音做爆款 → 红果变现。

5. 平台 3 · 番茄畅听(中老年最爱)

玉哥平台分析

📖 番茄 · 中老年蓝海

用户画像:

  • 1.5 亿+ 月活
  • 40-65 岁主力(60%)
  • 番茄小说读者转化(已有付费习惯)
  • 愿意为长剧付 ¥50-100

收益模式:

  • IAP 付费分账(主)
  • 平均 ARPU ¥20-40(高于红果)

内容偏好:

  • 年代 / 重生 / 家庭伦理
  • 反派嘴脸清晰(中老年观众要"看得清坏人")
  • 慢节奏 + 长剧情

📌 玉哥经验:番茄 = 中老年漫剧首选。重生 / 年代题材在番茄收益是抖音的 2-3 倍。

6. 平台 4 · 快手(下沉市场)

玉哥平台分析

🎬 快手 · 下沉用户

用户画像:

  • 4 亿+ DAU
  • 30-50 岁主力
  • 三四线城市 + 农村(60%)
  • 付费意愿中等

收益模式:

  • 短剧分账(类似抖音)
  • ¥1-3/万播放
  • 广告分成

内容偏好:

  • 战神 / 龙王 / 乡土 / 重生
  • "草根逆袭"题材最爆

📌 玉哥经验:快手 = 抖音的"下沉版"。同一内容抖音爆了 → 快手也爆(几乎不用改)。

8. 海外平台 AI 译制流程

玉哥 AI 译制 SOP

🌍 漫剧出海 5 步

  1. 中文剧本 → 用 ChatGPT 翻译成英文(口语化)
  2. 中文配音 → 用 ElevenLabs 配音英文版(G-3 教)
  3. AI 视频 → 用 Sora / Hailuo 跑英文 prompt
  4. 口型同步 → Sync.so 同步英文嘴型(G-7)
  5. 上传平台 → ReelShort / DramaBox 等

耗时:80 集翻译 + 配音 = 3-5 天(含 AI 等待时间)。

📌 玉哥经验:先做 1 集试水(英文 + 1 平台),数据好再批量。

9. 平台选择决策树

玉哥决策树

🌳 你是哪种情况?

情况 1:第一次做漫剧 / 试水 → 抖音 + 红果(2 个)。

情况 2:男频爽文(战神 / 龙王) → 红果 + 抖音 + 快手(3 个)。

情况 3:女频甜宠 / 闪婚 → 红果 + 抖音 + 番茄(3 个)。

情况 4:中老年题材(重生 / 年代) → 番茄 + 红果(2 个)。

情况 5:海外剧(英文) → ReelShort(试水)→ DramaBox(扩展)。

情况 6:东南亚市场 → ShortMax + DramaBox。

情况 7:全渠道铺 → 4 国内 + 4 海外 = 8 平台(成熟工作室)。

11. 上传规格统一

玉哥上传 SOP

📤 漫剧上传 5 件统一

  1. 尺寸:9:16 竖屏 1080×1920(H-2 教)
  2. 格式:MP4 + H.264
  3. 时长:单集 60-180 秒(学员中位数 90 秒)
  4. 封面:9:16 + 主角 + 4 字关键词(H-5 教)
  5. 标题:含主角名 + 反差词(如"龙王归来:妻子当众被羞辱,3 秒后全场跪下")

12. 学完这节能做啥

  • 知道国内 4 大平台(抖音 / 红果 / 番茄 / 快手)的特点
  • 知道海外 4 大平台(ReelShort / DramaBox / SkyReels / ShortMax)
  • 能给题材选对平台(男频→红果 / 中老年→番茄 / 海外→ReelShort)
  • 知道 AI 译制流程(ChatGPT 翻译 + ElevenLabs 配音)
  • 能给 80 集算收益(¥10,000-50,000 国内 / $500-5,000 海外)

13. 常见误解

❌

"发一个平台就够了" · 错。漫剧 80% 学员 3+ 平台同时发。同一内容 多平台发,收益 ×3-5(边际成本几乎为 0)。

❌

"海外 = 躺赚" · 错。90% 中国公司出海亏损。ReelShort 母公司仍亏。出海是"中后期升级",不是新手第一选择。

⚠️

"抖音流量大 = 收益高" · 部分对。抖音流量是红果的 3 倍,但单播放收益只有红果的 1/5。100 万播放:抖音 ¥3,000 vs 红果 ¥15,000。

⚠️

"番茄 / 红果 / 抖音 三选一" · 错。三者用户不同(番茄中老年 / 红果下沉 / 抖音全民),同一漫剧发 3 个 = 收益 ×3(内容不用改)。

14. 本节小练习

  1. 挑一部你做完的漫剧(或第 1 集),选定 3 个目标平台
  2. 用 H-2/H-5 的规格导出 9:16 视频 + 封面
  3. 写 3 个平台的不同标题(各平台用户偏好)
  4. 上传到 3 个平台,记录 24/72 小时数据
  5. 对比 3 平台的点击率 / 完播率 / 收益
  6. 挑选数据最好的 1 个平台作为"主战场",后续 80 集重点投入
