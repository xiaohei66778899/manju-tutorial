# AI and the novel: how to use ChatGPT to write a full-length book

- **来源 URL**: https://www.cometapi.com/ai-and-the-novel-how-to-use-chatgpt-to-write-a-full-length-book/
- **作者/站点**: CometAPI（AnnaAI 模型与 API 研究团队）
- **发布日期**: 2026-09-03（更新）

## 核心观点摘要（中文）

一篇工程化、可复现的长篇小说写作指南，核心立场：不要说"写一本小说"，而要用"人在环中（human-in-the-loop）"的纪律化流程。六步专业工作流：①规划阶段先定类型/基调、目标字数（中篇 6–9 万、史诗 9–12 万+）、出版路径；②建角色档案（dossier：姓名、三个怪癖、说话方式、最深恐惧、三个转折点）与情感弧图（30%/60%/100% 情绪落点），并做逐章场景清单；③分块（Chunking）——只让模型一次写 800–1500 词的场景，每章 3–6 个场景，每场景一句话目标+钩子收尾，以降低幻觉漂移；④控制声音风格——贴 200–500 词风格样本、用"把句子缩短 20%、副词减半"这类行级改写指令而非重生成；⑤迭代式编辑：起草→结构（情节/弧光）→角色一致性→行级→校对→试读，并用脚本做名称/时间线冲突的程序化检查；⑥事实核查与文化敏感性。文章强调超大上下文窗口与文件上传/自定义指令等"生产工具特性"让长篇创作成为可能，但也警告幻觉、作者署名权争议与多 Agent 并行带来的认知负荷。给出了"项目系统提示词"和模块化场景写作提示词模板。

## 一句话推荐理由
结构最完整的"专业编辑流程"映射到 AI 写作的指南，把场景分块、角色档案、多轮编辑 pass 和程序化一致性检查讲得非常可落地。
