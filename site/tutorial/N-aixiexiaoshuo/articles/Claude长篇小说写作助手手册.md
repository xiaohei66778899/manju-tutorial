# Novel Writing Assistant（Claude Code 长篇小说写作助手 Playbook）

- **来源 URL**: https://www.claudecodehq.com/playbooks/novel-writing-assistant
- **作者/站点**: Claude Code Playbooks（社区官方手册站）
- **发布日期**: 2026（页面更新于 2026-07）

## 核心观点摘要（中文）

一份面向 Claude Code 的长篇小说一致性管理手册，直击"写到 4 万字后主角瞳色变了两次、第 5 章死的人第 12 章还在吃饭"的通病。核心是建一个集中式 **Story Bible（故事圣经）** 目录结构：Characters（主角/反派/配角）、World（地点、魔法体系、历史、规则）、Plot（大纲、时间线、线索）、Style（叙事声音、主题）、Chapters（各章正文）。手册给出了可直接套用的"人物档案模板"（基本信息、外貌、性格/优缺点/恐惧/欲望、背景、说话风格与口头禅、情感弧光起点终点、一致性注意事项）。工作流分三段：写前（查圣经相关条目、回顾上一章结尾、记下待收线索、确认 POV 角色当前状态）、写中（保持人物声音、核对时间线、遵守世界规则、记录新引入元素）、写后（把新元素回写圣经、标记潜在矛盾、记录线索开合、更新时间线）。每章交付前有一张一致性检查清单（名字拼写、外貌匹配、时间线合理、无矛盾、声音区分、遵守世界规则）。还提供了"写作命令/编辑命令/圣经管理命令"的指令样例，以及"人物声音雷同就补口头禅、剧情漏洞就跑时间线检查、与前文矛盾就修正新章或注明 retcon"的排错指南。

## 一句话推荐理由
把"故事圣经+写前/写中/写后三段式+一致性检查清单"模板化的现成手册，配人物档案模板和可直接复制的指令，专治长篇人设/时间线崩坏。
