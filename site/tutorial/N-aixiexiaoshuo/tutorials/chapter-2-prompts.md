# 第 2 章 提示词基础

> **教学目标**：学完本章，你能用 CRISPE 框架写出"可直接执行"的写作提示词（而非"写得有文采"这种空话），并掌握反向提问、边界控制两个让 AI 高质量输出的关键技巧。

---

## 2.1 核心认知：提示词是合同，不是聊天

把提示词当成与 AI 签的一份"创作合同"（出自 DeepSeek-V4 提示词终极指南的 CRISPE 框架）。合同五要素缺一不可：

| 要素 | 错 | 对 |
|---|---|---|
| **C 角色** | "你是作家" | "你是擅长余华式冷静笔调写乡土文学的作家" |
| **R 请求** | "写个故事" | "续写本章 3000 字，必须包含主角身世反转" |
| **I 背景** | 不交代 | 把前文、人物设定、世界观大纲一股脑丢进上下文 |
| **S 限制** | "写得合理点" | "禁止出现任何现代科技词汇""每段对话不超过三行""不用'然而'和'深邃的眼眸'" |
| **P 风格** | "有文采" | "口语化像朋友聊天""模仿汪曾祺" |

**一句话判别标准**：把提示词里的每个动词换成具体动作、每个形容词换成可检查的规则，做不到的提示词就是空话。

## 2.2 五个效率技巧（全部有来源，直接照用）

1. **用具体文风标签替代抽象形容词**：写"模仿汪曾祺的克制短句"，不写"写得有文采"。
2. **直接卡字数**：写"本章 3000 字，每段不超过 3 行"，模型对字数要求执行得远比想象中好。
3. **加防编造禁令**：开头加粗写"禁止生成设定资料之外的人名、地名、数据"，防它瞎编。
4. **结尾要多版本**：加一句"请再给出一个完全不同的走向版本"，防止只出最安全的陈词滥调。
5. **用反思做自我修正**：输出后追加"反思刚才的回答，指出 3 个最明显的问题并重写"，比直接否定重来有效。

**两个高级技巧**：

**反向提问法**（出自《做故事架构师而非码字工》）：别问 AI"写什么"，而是给它一个设定，问"这样写行不行、有几个切入点"。AI 会变成高强度头脑风暴伙伴，而不是套路生成器。示例：给它"主角每天早上口袋多一张当天死亡预言纸条"的设定，让它列三个避开"阻止死亡"老套逻辑、侧重心理变化的切入点。

**边界控制法**（出自 GPT-4 从零写整本实验）：AI 写段落时总爱"往前冲"写到还没发生的情节。破解：先写该段的开头段落和结尾段落，再让 AI 填中间——用两端把它的发挥框住，就不会跑偏到后面章节去。

## 2.3 可直接复制的提示词模板

### 模板 A：CRISPE 完整模板（通用，替换 {变量} 即用）

```text
【角色】你是{具体的文风+领域描述，如：擅长余华式冷静笔调、专写都市现实题材的小说家}。
【请求】{一个具体动作，如：续写本章正文 3000 字}，必须包含{必备要素，如：主角身世反转的揭示}。
【背景】以下是前情与设定：{粘贴前文结尾 500–1000 字 + 相关人物/世界观设定条目}。
【限制】禁止出现：{禁忌词/要素，如：现代科技词汇、'然而''深邃的眼眸'}；
每{段/章}不超过{数字}字/行；视角限定{第一人称/第三人称限知}；
结尾必须留下{悬念钩子类型，如：一个反常细节}。
【风格】{具体风格描述，如：口语化、短句、克制，每章 3000 字}。
【多版本】正文之外，另给一个完全不同的走向版本。
```

### 模板 B：长篇小说章节续写任务书（基于 DeepSeek-V4 终极指南范例）

```text
你是一位专写{类型，如：架空历史权谋}的长篇连载作者。
请续写第 {N} 章正文，要求：
1. 第三人称限知视角，跟随{主角名}，不少于 {1500–3000} 字；
2. 承接上一章结尾：{一句话概括上一章结尾状态}；
3. 本章必须推进{主线任务或冲突}，并让{配角名}的动机发生一次可见变化；
4. 禁用现代词汇与设定外的新地名/人名/能力；
5. 结尾用一个悬念钩子收束（悬念类型：{如：一个反常细节/未落地的决定}）；
6. 另给一个截然不同的剧情走向版本（200 字概要即可）。
```

### 模板 C：爆款开篇生成（来自知乎盐选实操手册，付费短篇向）

```text
你是一位深谙网络小说付费逻辑的顶级策划。
请生成第一章，1500 字，目标读者为{平台，如：知乎盐选}付费读者。要求：
1. 拒绝平铺直叙，开篇直接从冲突切入，前 1000 字必须抛出最强悬念；
2. 利用{重生/掉包/身份反转等}信息差制造悬念，逐层披露；
3. 强化感官描写，对话带潜台词，避免交代式叙述；
4. 结尾抛出一个意外钩子，逼读者点下一章。
```

### 模板 D：反向提问法（头脑风暴专用）

```text
我有一个故事设定：{一句话设定，如：主角每天早上口袋多一张当天死亡预言纸条}。
请以"资深剧情策划"身份，给出 {3} 个不落俗套的剧情切入点，
要求：避开{常见套路，如：努力阻止死亡最后成功}，侧重{方向，如：人物心理变化与信息差}。
每个切入点用 2 句话说明它的核心张力在哪里。
```

## 2.4 操作步骤

1. **写**：按模板 A 填好五个要素，背景一定要贴实际前文，不要省略。
2. **发**：一次只发一个任务（续写就续写，不要"续写+润色+写大纲"）。
3. **查**：输出后对照【限制】逐条检查；字数不够/用词犯规直接指出来让它改。
4. **迭代**：不满意时用"强制要什么 + 禁止不要什么"的方式指出，反复打磨——首轮输出几乎不可能一次满意，这是正常现象（主流写作工具官方也强调这点）。
5. **沉淀**：改到满意后，把这条提示词存成一个文件（或工具的项目说明里），下次同类任务直接复用。

## 2.5 常见坑 + 解决方法

| 坑 | 现象 | 解法 |
|---|---|---|
| 把命令当聊天 | "帮我写点东西"→ 输出全是水 | 用 CRISPE 五要素写完整合同 |
| 约束太模糊 | "写得生动点"→ 模型自由发挥 | 换成可检查规则：字数、句式、禁词、视角 |
| 一次塞太多不搭边任务 | 要它同时写大纲+正文+润色，输出每样都糊 | 一次一个任务；要审稿就单独开一轮换角色 |
| AI 味高频词 | "然而""不可否认""深邃的眼眸""嘴角勾起弧度"反复出现 | 建"AI 高频词黑名单"，写完后处理：命中词触发局部重写 |
| 让 AI 自己定剧情走向 | 它当章把冲突解决掉，后文没得写 | 走向由你定，AI 只执行本章节拍（详见第 4 章大纲） |
| 不交代背景 | 模型按自己的想象补设定，与前文矛盾 | 每次续写都带上"前文结尾 + 相关设定条目" |
