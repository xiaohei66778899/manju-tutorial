# 第 1 章 工具选型与配置

> **教学目标**：学完本章，你能根据自己的写作语言（中文/英文）、目标（网文量产/严肃长篇）和预算，选出合适的 AI 工具组合，并完成 API 密钥、上下文、写作偏好的基础配置。

---

## 1.1 先搞清三层工具架构

市面上所有"AI 写小说工具"其实分三层，多数人只用了第一层：

| 层级 | 代表 | 干什么用 |
|---|---|---|
| 通用大模型对话助手 | Claude、ChatGPT、DeepSeek、豆包、Kimi、通义、Gemini | 主力写作引擎：出大纲、写章节、润色、审稿 |
| 专用写作工作台 | FeelFish、灵蟹创作、蛙蛙写作、AI_NovelGenerator | 自带设定库/章节管理/一致性检查，把长篇组织成工程 |
| 写作工作流 / Agent | chinese-novelist-skill、awesome-novel-skill、writing-agent | 把"写一本小说"拆成阶段流水线，自动跑完 |

**结论先行**：新手先用第一层免费版跑通"大纲→章节→润色"；写多卷长篇且要管设定时上第二层；要批量量产或自动化时再上第三层。别一开始就搭全套，工具只是手段。

## 1.2 选型三问

根据素材里交叉验证过的选型建议（`tools.md` 第四节 + 各工具官网数据），按三个问题对号入座：

**Q1：写中文还是英文？**
- 中文：豆包、DeepSeek、Kimi、通义千问、文心一言（国产对中文语境与网文"网感"更好）
- 英文：Claude、ChatGPT（非中文原生，且访问需自行解决网络；本教程以中文写作为主）

**Q2：目标是什么？**
- 网文量产（中文）：主力选豆包（网感强、生态全）或 DeepSeek（免费/极便宜、可批量）；要管理多卷设定和大纲时用 Kimi 的超长上下文一次喂入全书梳理
- 长篇严肃创作：中文用 Kimi（超长上下文）+ Claude（文笔打磨、克制润色）组合
- 付费短篇/盐选：DeepSeek 或豆包起稿，靠提示词打爽点（见第 2 章）

**Q3：预算多少？**
- 零预算：DeepSeek 网页版完全免费 + 豆包/通义免费额度即可起步
- 低价档：通义办公助理 ¥19/月、Google AI Plus $4.99/月
- 一步到位：Claude Pro $20/月 或 ChatGPT Plus $20/月 性价比最稳

> 数据口径：价格核实时间 2026-09，以官网实时定价页为准（`tools.md` 已注明逐项来源）。

**模型分工建议**（来自自出版作者六步法）：头脑风暴、出高概念提案用轻量模型（免费档即可）；从写梗概开始切换到强模型（如 Claude、GPT-4o 档）；长篇连贯性依赖长上下文，Plus/Pro 档的长上下文是硬需求。

## 1.3 关键配置参数

不管用哪家，核心参数就三个：

| 参数 | 推荐值 | 说明 |
|---|---|---|
| temperature | 0.7 左右 | 创意度。大纲/设定这类要稳定输出的任务降到 0.5 更稳；写作 0.7 左右是主流工具默认（AI_NovelGenerator 默认即 0.7） |
| max_tokens | 8000–8192 起 | 单次输出上限。写整章建议 8000+，否则会被截断 |
| 上下文 | 越长越好 | 长篇连贯性的硬约束。Kimi 百万级上下文、Claude 超长上下文是写长篇选型的关键理由 |

其他值得注意的配置：
- **模型切换**：草稿用便宜快模型，正式写作、润色、审稿用强模型，甚至刻意换不同模型做"第二双眼睛"审稿（多 Agent 架构文章的做法）。
- **云端 vs 本地**：要隐私或免费可跑本地（Ollama），灵蟹创作等工具支持 BYOK 接本地模型；国产开源（Qwen、DeepSeek）可私有化部署。

## 1.4 可直接复制的提示词模板

### 模板 A：创作协作者系统提示词（配置到工具的"自定义指令 / 系统提示词 / 项目说明"里）

这个模板让 AI 从"一次性回答"变成"你的长期写作协作者"，是第 1 章最该先配好的东西：

```text
你是我的{小说类型}写作协作者，负责协助完成一部{预计字数}字的长篇小说创作。
协作规则：
1. 每轮只处理我指定的单一任务（出大纲 / 写章节 / 润色 / 审稿），不要擅自扩展；
2. 涉及设定时，先引用我提供的设定材料，不得凭空新增未约定的人名、地名、能力；
3. 输出正文时，严格遵循我给出的字数、视角、禁止项等约束；
4. 我要求多个版本时，给出 N 个完全不同的走向，不要给同义改写；
5. 发现前后文矛盾（人设、时间线、伏笔）时，先指出矛盾再继续，不要默默糊过去。
```

### 模板 B：让 AI 自配专家（来自 DeepSeek-V4 提示词终极指南）

不指定具体大师，只描述领域和目标，让模型从知识库反向拼出专家人格——比硬说"你是个作家"有效得多：

```text
你是一位精通{领域描述，如：网络小说爽点节奏与章末悬念设计}的顶级专家。
请以这个身份，为以下目标工作：
{目标，如：为一本现代都市重生题材小说设计第 3–5 章的大纲}
要求：
- 先说明你会用哪些专业方法处理这个任务（两三句即可）；
- 然后直接给出成品，不要解释过程。
```

## 1.5 操作步骤

### 路径 1：通用助手入门（零成本，10 分钟跑通）

1. 任选 DeepSeek（chat.deepseek.com）、豆包（doubao.com）、通义（tongyi.com）、Kimi（kimi.com）注册，均为免费网页版。
2. 新建一个专门会话/项目（Kimi、Claude 的 Projects、ChatGPT 的 Projects 都支持长期资料挂载），把模板 A 贴进系统提示词或项目说明。
3. 把你的设定材料（第 3 章会教你建）作为首条消息喂进去，之后所有章节都在这个会话里写。

### 路径 2：本地开源工作台（AI_NovelGenerator 为例）

1. `git clone https://github.com/YILING0013/AI_NovelGenerator`（素材已在 `E:\AI写小说\repos\AI_NovelGenerator`）。
2. `pip install -r requirements.txt`（Python 3.9+，推荐 3.10–3.12）。
3. 编辑 `config.json` 填入 API Key：支持 DeepSeek、OpenAI、Gemini 等，也可填本地 Ollama 兼容接口；模型默认 `deepseek-v4-flash`（temperature 0.7，max_tokens 8192）。
4. `python main.py` 启动 GUI，从"小说设定工坊"开始建世界观/角色/剧情蓝图。
5. 想要一键图形化、不折腾环境，可换 WenShape：下载 Windows Release 包双击 exe 即可。

## 1.6 常见坑 + 解决方法

| 坑 | 现象 | 解法 |
|---|---|---|
| 免费版上下文太小写长篇 | 写到十几章，角色忘了早期设定、伏笔丢失 | 换长上下文工具（Kimi 百万级）或升级付费档；同时必须维护设定集（第 3 章），不能只靠模型记忆 |
| 一个模型用到底 | 后文质量下滑、同一种 AI 味贯穿全书 | 草稿用快模型、正式写作/润色用强模型；审稿刻意换一个模型做第二视角 |
| 英文向工具不适合中文 | NovelAI 等英文向工具写中文效果差 | 中文写作直接走国产工具 |
| temperature 拉满 | 剧情乱飞、设定崩塌 | 写作保持 0.7 左右，大纲/设定类任务降到 0.5 |
| API Key 泄露/费用失控 | 账户被刷、账单爆炸 | Key 只放自己设备；平台开用量限额；BYOK 类工具（如灵蟹创作）注意按模型计费差异 |
| 一次性让 AI 写一整本 | 越写越糊、前后矛盾 | 拆场景写（单次 800–1500 词，每章 3–6 个场景）；工程极限单次 2000–3000 字，别让它一次吐一万字 |
