# 第 5 章 章节扩写

> **教学目标**：学完本章，你能把一条章纲拆成 3–6 个场景，用"分块 + 边界控制 + 四维描写"的方法写出画面感强、不跑偏、不糊弄的章节正文。

---

## 5.1 核心原则：一次只写一小块

AI 长篇写作最大的质量杀手是"一次写太多"。所有素材在同一件事上达成了共识：

- **分块写作**（CometAPI 专业工作流）：只让模型一次写 **800–1500 词** 的一个场景，每章 3–6 个场景，每个场景给一句话目标 + 钩子收尾——分块是降低幻觉漂移的主要手段；
- **工程极限**（多 Agent 架构）：单次生成别超过 2000–3000 字，超过后质量断崖；
- **干净上下文**（34 本经验）：每章在独立上下文里跑，禁止一次写多章——上下文越长，质量越糊。

所以"扩写一章"的正确动作不是"写一章"，而是"按细纲逐个场景写，每个场景单独发指令"。

## 5.2 三个关键技巧

1. **边界控制（由外向内）**（GPT-4 从零写整本实验）：AI 写段落时爱"往前冲"写到后面才该发生的情节。破解：先写该段的**开头段落和结尾段落**，再让 AI 填中间——用两端把它框住，它就跑不到别的章节去。
2. **四维拆解**（51CTO 四步实战法）：AI 写作缺画面感，是因为指令太笼统。把每个子场景拆成四维单独下指令：**环境设施、人物动作、心理活动、感官体验**。一次只强化一维，画面感立刻上来。
3. **上下文窗口**（多 Agent 架构的滑动窗口）：写第 N 章时只喂"全局大纲 + 第 N-3 至 N-1 章摘要 + 本章细纲"，而不是把全书都贴进去。既有衔接，又不会让模型被旧文带偏或遗忘重点。

## 5.3 可直接复制的提示词模板

### 模板 A：场景写作任务书（分块法核心模板）

```text
请写一个场景，800–1500 字。
【场景目标】{一句话：本章/本场景要达成什么}
【场景位置】第 {N} 章 · 场景 {X}/{Y}（全章共 Y 个场景）
【前情衔接】上一场景结尾：{一句话}
【出场人物】{名单}（当前状态：{如：林晚左臂受伤，情绪压抑}）
【本场景要求】
1. 从上一场景结尾直接切入，不重复交代；
2. 用动作和对话推动，禁止大段心理独白直述；
3. 结尾用一个钩子收束（钩子类型：{如：一个反常细节/一句没说完的话}）；
4. 遵守世界观规则：{粘贴相关设定条目}。
```

### 模板 B：边界控制（先首尾后中间）

```text
我需要写场景「{场景名}」。先按以下顺序工作：
第 1 步：写这个场景的开头段落（{100–150} 字），定下情绪和切入点；
第 2 步：写这个场景的结尾段落（{100–150} 字），定下钩子和落点；
第 3 步：在两端之间填充中间内容（{600–1200} 字），只允许写首尾之间会发生的事，
        不得写到结尾之后的情节，不得提前使用后续伏笔。
```

### 模板 C：四维描写强化（画面感专项）

```text
请强化以下段落（或场景）的画面感，输出改写版。
原始内容：{粘贴正文或场景描述}
按四维逐一强化，每维一个版本：
1. 环境设施：明确空间布局、光线、声音、气味；
2. 人物动作：具体到肢体细节（如"手指敲桌面"而非"他思考着"）；
3. 心理活动：只写可见的心理外化（动作/表情/生理反应），不写"他心想"式直述；
4. 感官体验：至少三种感官细节。
每个版本一段，不要合并。
```

### 模板 D：续写衔接（多 Agent 滑动窗口）

```text
你现在要续写第 {N} 章（共 {M} 章）。
可用上下文（只许用这些，不得自行补充）：
- 全局大纲：{粘贴相关章节大纲}
- 第 {N-3} 至 {N-1} 章摘要：{粘贴 3 段各约 200 字的摘要}
- 本章细纲：{粘贴第 4 章模板 D 生成的细纲}
要求：承接摘要结尾，严格按细纲推进；每完成一段正文，用 1 句话回写本章进度摘要。
```

## 5.4 操作步骤

1. **取细纲**：从第 4 章的章纲文件里取出当前章，确认场景清单（3–6 个）。
2. **逐场景发指令**：每个场景用模板 A 单独发一次（附上前一场景结尾）。不追求一次写完一章。
3. **画面感不够时**：用模板 C 做四维强化，一次只强化一维，改到满意为止。
4. **怕跑偏时**：用模板 B 边界控制，先定首尾再填中间。
5. **续写新章**：用模板 D 组织上下文（大纲 + 前 3 章摘要 + 本章细纲），保持每章独立上下文。
6. **回写进度**：每写完一章，把 1–2 句章节摘要回写进 `Chapters/`（下一章续写要用它，第 7 章详述）。

## 5.5 常见坑 + 解决方法

| 坑 | 现象 | 解法 |
|---|---|---|
| 一次让 AI 写整章/整本 | 越写越糊、前后矛盾、AI 味集中 | 分块：单次 800–1500 词，每章 3–6 个场景逐个发 |
| 场景开头总重复交代 | 每章开头都从"清晨，他醒来"开始 | 模板 A 要求"从上一场景结尾直接切入" |
| 画面感缺失 | 全是"他思考着/她感到"式概述 | 四维拆解逐维强化；心理活动只写外化表现 |
| 段落往前冲 | 写到后面才该发生的剧情 | 边界控制：先写首尾两端，再填中间 |
| 续写时角色忘了前文 | 行为与上一章断裂 | 滑动窗口：喂"前 3 章摘要 + 本章细纲"而非全书 |
| 输出被截断 | 写到一半停了 | 提高 max_tokens（8000+），或把场景再拆小 |
