# 第 11 章 网文商业写作：黄金三章与爽点设计

> 一句话教学目标：学完本章，你能用 AI 设计出"前 300 字留人、三章内给爽点、章末逼人点下一章"的商业化开篇与节奏，而不是写一本没人读完的书。

---

## 11.1 先分清：文学写作 vs 商业写作

付费课反复强调同一件事：**商业网文的第一指标是留存，不是文笔**。读者点开第一章，前 300 字决定他看不看下去，前三章决定他订不订阅。所有技巧（钩子、爽点、断章）都服务于一个目标：让读者产生"下一章必须看"的冲动。

文笔是放大器，不是入口。先把"留人"的工程做对，再谈风格。

---

## 11.2 前 300 字钩子：三选一，必须出现

阅文作家专区的高赞方法论：**开篇 300 字内，悬念、冲突、金手指亮相，三选一必须出现**；每章 3000 字，第 1 章 300 字内就要抓住人 ["https://write.qq.com/portal/community/topic/detail/96381521685955401"]。

三种钩子：

| 类型 | 作用 | 示例思路 |
|---|---|---|
| 悬念 | 让读者想知道"怎么回事" | 主角醒来发现自己在陌生房间，手机显示三天后 |
| 冲突 | 让读者替主角捏一把汗 | 主角被当众退婚 + 家族断绝关系 |
| 金手指 | 让读者期待"这能力怎么用" | 重生者知道三个月后的灾难，但没人信他 |

付费课口径（黄金三章 = 代入感 + 金手指 + 小爽点）：前 300 字必须抛出**核心冲突、讲清主角缺什么、被逼到什么地步** ["https://www.iesdouyin.com/share/video/7683643642099076361"]。新人常犯的错：前 3000 字还在介绍门派背景——读者早退出了。

### 模板A：黄金三章结构生成

```text
你是爆款网文开篇策划。请为我的小说设计黄金三章的任务卡。

【我的设定】
题材：{题材，如：都市重生}
主角：{主角身份与处境}
金手指：{金手指能力}
目标读者：{如：番茄小说男频 18-30 岁}

【结构要求】
第一章【留人】：前 300 字给出悬念/冲突/金手指三选一，讲清主角缺什么、被逼到什么地步；本章结尾一个钩子。
第二章【立矛盾】：核心矛盾确立，读者要明白这本书要讲什么；安排一个打脸/反转场景。
第三章【小高潮】：第一个爽点兑现，让读者觉得"这书能看"，结尾埋一个世界级秘密或更大的钩子。

【输出格式】
每章输出：章节任务 | 开篇 300 字设计（可直接用）| 本章情节要点（3 个 beat）| 章末钩子。
不要解释过程，直接给成品。
```

## 11.3 爽点设计：极限铺垫 + 情绪节拍

爽点不是"打脸"这么简单，它的核心公式是**铺垫越狠，爆发越爽**。网文创作方法论里的"极限铺垫原则"：一切爽点的爆发力都源于其反方向的极限铺垫——必须遵循"欲扬先抑"，且困境要立体化（主角个人 + 家庭 + 阶层 + 时代背景多层受压）["https://programnotes.cn/ai-deepseek-novel/index.html"]。

情绪节拍表（付费课标准四拍）：

| 节拍 | 作用 | 时长控制 |
|---|---|---|
| 起（铺垫/受辱/绝境） | 积累情绪势能 | 1-3 章内完成一次循环 |
| 承（反击准备） | 让读者看到反攻希望 | 快节奏，不拖 |
| 转（反转/打脸） | 情绪集中释放 | 单章内给足细节 |
| 结（阶段结算） | 收获 + 新目标 | 让读者满足后再抛新钩子 |

### 模板B：爽点节拍设计

```text
你是网文情绪节奏设计师。为下面的情节设计一段完整的爽点节拍。

【情节】{要写的爽点情节，如：主角在宗门大比上被当众羞辱后绝地反击}

【设计要求】
- 按"铺垫→反击→爆发→结算"四拍输出；
- 铺垫部分写清楚：主角被压到什么地步（至少两层压力：当众 + 深层原因）；
- 爆发部分要求：打脸要有具体动作和围观者反应，不要一句带过；
- 结算部分要求：给出物质收获 + 情绪出口 + 一个新悬念；
- 每拍给出 200-400 字的正文示例（可直接用）。

【输出格式】四拍小节标题 | 每拍正文示例 | 每拍结尾的情绪状态标注。
```

## 11.4 期待感管理：让读者追更的底层机制

付费课反复讲的"读者期待感管理"：通过**前置伏笔、明牌反派、阶段目标**，让读者持续对后续兑现产生焦渴感 ["https://www.iesdouyin.com/share/video/7683202852226977060"]。

三个落地手段：
1. **前置伏笔**：第 1-3 章埋的伏笔，明确告诉读者"这个东西后面会用"（如神秘信件、玉佩、系统提示）；
2. **明牌反派**：别把反派藏到最后，开头就亮出强大到绝望的反派/势力，读者等着主角翻身；
3. **阶段目标**：每 20-30 章一个明确的大目标（复仇对象、势力争霸、秘境开启），让读者有"追到那个节点"的理由。

## 11.5 断章钩子：章末逼人点下一章

付费课"章末断章钩子"方法论：在单章结尾制造必须看下一章的理由 ["https://www.iesdouyin.com/share/video/7683202852226977060"]。三种经久不衰的钩子：

| 类型 | 写法 | 适用 |
|---|---|---|
| 悬念型 | 一个信息突然反转（"他不是……"） | 悬疑/玄幻/都市 |
| 威胁逼近型 | 危机倒计时（"三日后，大比开始"） | 升级流 |
| 情感型 | 关键人物表态/出现（"她终于认出我了"） | 情感/都市 |

### 模板C：章末断章钩子生成

```text
你是断章钩子设计专家。请为本章内容设计 3 个不同方向的章末钩子。

【本章内容摘要】
{本章发生的事 + 当前角色的状态 + 你希望读者期待什么}

【输出要求】
- 给出 3 个钩子，类型分别偏：悬念反转 / 威胁逼近 / 情感冲击；
- 每个钩子给：1 句正文示例（可直接贴在章末）+ 它能勾起读者什么期待；
- 最后推荐 1 个最适合本作品类型的，说明理由。
```

## 11.6 节奏管理：高潮的分布

付费课节奏规则（直接可用）：**每 5-8 章一个小高潮，每 20-30 章一个大爆发点，避免连续超过 3 章"日常/过渡"**；每章必须包含：章节标题（有悬念感）、核心事件（推进了什么）、情绪定位（燃/虐/甜/悬疑/日常）、结尾钩子（为什么看下一章）["https://www.iesdouyin.com/share/video/7664813384311820468"]。

写大纲时就按这个节拍排布（联动第 4 章大纲模板，在卷纲里标出高潮章）。

## 11.7 操作步骤

1. **开篇前**：用模板A 生成黄金三章任务卡，人工检查三章各自完成"留人/立矛盾/小高潮"；
2. **写爽点**：用模板B 设计节拍，重点检查铺垫层数（≥2 层压力）和打脸的具体度；
3. **每章收尾**：用模板C 出 3 个钩子选 1，禁止"无钩子收尾"；
4. **卷纲排布**：按 5-8 章小高潮 / 20-30 章大爆点标注全卷节奏（联动第 4 章卷纲模板）；
5. **发书后**：用真实数据验证——留存差优先改前 300 字，完读差优先改断章。

## 11.8 常见坑 + 解决方法

| 坑 | 现象 | 解法 |
|---|---|---|
| 前 300 字写背景 | 读者 2 秒退出 | 300 字内必给钩子（悬念/冲突/金手指三选一） |
| 铺垫不足直接爽 | 爽感廉价、记不住 | 极限铺垫：至少两层压力 + 欲扬先抑 |
| 每章都平收 | 追读率低 | 模板C 出钩子，禁止无钩收尾 |
| 连续日常章 | 读者弃书 | 单章即"日常"也要内嵌小冲突，超 3 章连续过渡必须砍 |
| 爽点一句带过 | 读者无满足感 | 爆发要有具体动作 + 围观反应 + 结算收获 |
| 埋了伏笔忘回收 | 读者骂街 | 伏笔登记进设定集（联动第 7 章），写明"预计第几章回收" |
