# 第 6 章 对话打磨

> **教学目标**：学完本章，你能为每个角色建立"说话声音"（风格/口头禅/句式），写出带潜台词、能区分角色、不啰嗦的对话，并清除对话里的 AI 味。

---

## 6.1 对话是角色区分的唯一武器

AI 写多人对话时最典型的毛病：**所有人说话一个腔调**。根因是它只按内容组织台词，不按人物声音组织。解法分两层：

1. **建角色声音卡**：每个人的说话方式写进人物卡（CometAPI 角色档案的"说话方式"字段：风格 + 口头禅 + 句式偏好），写作时喂给 AI；
2. **潜台词优先**（做故事架构师 + 多 Agent 架构都点名）：对话不能"问什么答什么"，要让台词背后藏着没说出来的动机——这既是真实感来源，也是章末钩子的素材。

同时遵守 chinese-novelist 的黄金法则：**用动作和对话表现，不要直接陈述**（"她很生气"是陈述，"她摔了杯子"是表现）。对话要承担推动冲突的功能，不承担交代背景的功能——交代用动作和环境，不用对话直述。

## 6.2 三个关键技巧

1. **口头禅 + 句式锚定**：给每个角色一句专属口头禅或句式特征（如"林晚句尾爱加'罢了'，反派说话爱用反问句"），对话输出就立刻能区分。
2. **对话带潜台词**：让 AI 先写出"表面说的"和"实际想的"两层，再落成台词——直接把潜台词写进对话里，而不是只写在旁白里。
3. **压缩对话密度**（DeepSeek-V4 指南）：限制"每段对话不超过三行"，强制对话短促有力，避免长篇大论的台词独白。

## 6.3 可直接复制的提示词模板

### 模板 A：角色声音卡（并入人物卡）

```text
为角色 {角色名} 建立对话声音档案，输出为可直接存档的 markdown：
1. 说话风格：{如：短句、克制、从不表露情绪 / 话痨、爱比喻}
2. 口头禅/口头语：{给出 2–3 个专属表达，如"罢了""有意思"}
3. 句式偏好：{如：爱用反问句 / 句尾爱加语气词 / 从不使用感叹号}
4. 禁忌表达：{这个角色绝不会说的话，如：从不说"我恨你"，只说"你欠我的"}
5. 对话示例：给 2 句符合该声音的台词示范（场景：{随便一个场景}）。
```

### 模板 B：潜台词改写

```text
请改写以下对话场景，让台词带上潜台词。
原始内容：{粘贴对话}
要求：
1. 先列出本场景每个角色"表面想说的"和"实际想说的"（一行对照表）；
2. 按对照表重写台词：字面上说 A，但读者能读出 B；
3. 禁止把潜台词写进旁白直述，只能通过台词措辞和动作暗示；
4. 每段对话不超过 3 行，用动作/表情穿插打断长台词；
5. 保持每个角色的说话声音（口头禅与句式），不要统一腔调。
```

### 模板 C：角色声音区分检查

```text
以下是 {N} 个角色的对话片段：{粘贴对话}
请以"剧本医生"身份逐条检查：
1. 遮住角色名后，能否凭说话方式猜出是谁？把"声音雷同"的段落列出来；
2. 哪些台词可以直接删除而不损失信息（说明理由）；
3. 哪些台词可以换成动作/表情表现（给出替换动作）；
4. 输出修改后的对话版本，保持各角色口头禅与句式。
```

### 模板 D：冲突型对话升级

```text
请把以下对话改写成一场冲突升级的对手戏：{粘贴对话或场景描述}
要求：
1. 两人目标直接对立，各自在对话中亮出底线；
2. 对话分三个层次推进：试探 → 交锋 → 撕破（或达成危险共识）；
3. 每轮对话附带一个动作细节（肢体/表情/环境），替代情绪直述；
4. 结尾停在"话没说完"或"反应出乎意料"处，给下一场景留钩子；
5. 每段对话不超过 3 行。
```

## 6.4 操作步骤

1. **建档**：用模板 A 给每个主要角色建声音卡，存入人物卡（第 3 章模板 A 的"说话风格与口头禅"字段），2–3 个口头禅 + 句式偏好即可。
2. **写作时引用**：场景写作任务书（第 5 章模板 A）里带上出场角色的声音卡条目。
3. **写后打磨**：初稿对话如果平直，用模板 B 做潜台词改写，先列"表面/实际"对照，再重写台词。
4. **批量检查**：一场多人戏写完，用模板 C 让 AI 做声音区分检查——专治"所有人一个腔调"。
5. **关键对手戏**：用模板 D 升级冲突，让对话承担推进剧情的功能而不是交代信息。

## 6.5 常见坑 + 解决方法

| 坑 | 现象 | 解法 |
|---|---|---|
| 所有人一个腔调 | 遮住名字分不出谁在说话 | 声音卡 + 模板 C 定期做区分检查 |
| 对话是信息复读机 | 角色互相交代背景（"你知道的，我们三年前…"） | 交代信息改用动作/环境；对话只推进冲突 |
| 台词长篇大论 | 一个人说一页 | 限制每段 ≤3 行，用动作穿插打断 |
| 潜台词写成旁白 | "他嘴上说好，心里却想…" | 模板 B：潜台词只能藏在措辞和动作里 |
| 对话没有钩子 | 章末对话把话说尽 | 结尾停在"话没说完/反应出乎意料"，用对话收束做钩子 |
| 情绪全靠形容词 | "她愤怒地说" | 换成动作表现（"她摔了杯子"），删除情绪副词 |
