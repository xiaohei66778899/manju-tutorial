1. ComfyUI 是什么 · 为什么选它

💡

ComfyUI = 节点式 Stable Diffusion 工作流工具。把图片生成拆成"模型加载 + 提示词编码 + 采样器 + 解码"等可视化节点,拖拽连线就能跑。优势:可复现 / 可批量 / 可集成视频/LoRA/IP-Adapter;比 WebUI 更底层、更强大。

1.1 ComfyUI vs WebUI vs Fooocus 对比

维度WebUI (A1111)ComfyUIFooocus
界面表单式节点式表单 + 自动化
上手难度低中极低
工作流复用差强(JSON 一键导入)中
视频/动画需插件原生支持不支持
角色一致性需插件原生 IP-Adapter + LoRA弱
适合人群新手 / 单图短剧/漫剧(必须)完全新手

4. 基础 1:文生图工作流(SDXL)

6. 基础 3:提示词工程

6.1 提示词结构(权重顺序)

质量词(20%) + 主体(40%) + 细节(20%) + 风格(10%) + 负面词 正例(漫剧女角色): masterpiece, best quality, ultra-detailed, 1girl, 25 years old, long black hair, school uniform, standing in classroom, looking at camera, slight smile, soft lighting, cinematic composition, # 负面词 ugly, blurry, lowres, bad anatomy, extra fingers, watermark, text, deformed

6.2 权重语法

(keyword:1.5) # 权重提升 50% [keyword1:keyword2:0.3] # 0.3-1.0 之间过渡 AND / BREAK # 分段控制 [red:blue:0.5] # 50% 红 + 50% 蓝混合

7. 进阶 1:角色一致性 · 5 大方案

核心:AI 漫剧最大难点 = 同一角色 30 集中长相一致。5 大方案按成本递增:

方案原理工具成本效果
① IP-Adapter用参考图控制ComfyUI + IP-Adapter¥070% 一致(够用)
② IP-Adapter + 参考图高质量参考图 + 多角度IP-Adapter Plus¥080% 一致
③ IP-Adapter Face ID面部 ID 提取IP-Adapter FaceID¥085% 一致
④ LoRA 训练20-50 张图学角色ComfyUI + Kohya¥0(算力费)90% 一致
⑤ InstantID / PulID商业级换脸InstantID / PulID¥095% 一致

7.1 方案 2:IP-Adapter + 参考图(漫剧主流)

[IP-Adapter 漫剧节点树] LoadImage(角色参考图) ↓ IPAdapterUnifiedLoader(plus face) ↓ CLIPTextEncode (新场景) ↓ KSampler(weight=0.8, denoise=0.6) ↓ VAEDecode → SaveImage # 关键参数 weight: 0.7-0.8 # 太大变形,太小不一致 weight_type: linear # 比 cosine 更稳 start_at: 0.0 end_at: 0.8 # 80% 步数控制,留 20% 自由发挥

7.2 方案 3:IP-Adapter Face ID(更专业)

提取面部 ID 而非整图。优点:不受服装/姿势影响,只锁脸。缺点:需装 InsightFace + buffalo_l 模型。

8. 进阶 2:LoRA 训练(角色专属)

8.1 LoRA 训练硬件要求

角色 LoRA 规模推荐 VRAM训练时长
20 张图(简)8 GB30 分钟
30-50 张图(标准)12 GB1-2 小时
100+ 张图(精)24 GB3-4 小时

8.2 数据集准备(关键)

⚠️

数据集质量决定 LoRA 质量。规则:① 20+ 张不同角度/表情/服装;② 背景纯色或干净(避免学习背景);③ 图片 ≥ 1024×1024;④ 命名用触发词(例如"ych_")。

8.3 训练参数(标准)

[Kohya GUI 训练参数(SDXL LoRA)] pretrained_model: stabilityai/stable-diffusion-xl-base-1.0 output_dir: ./output/ych_lora/ resolution: 1024 train_batch_size: 4 num_epochs: 10 learning_rate: 1e-4 lr_scheduler: cosine network_rank: 32 # 32-64 平衡容量和速度 network_alpha: 16 save_every_n_epochs: 2 mixed_precision: fp16

8.4 训练流程 5 步

  1. 打标:用 JoyCaption2/BLIP 自动生成每张图描述
  2. 配置:Kohya GUI 填好参数
  3. 训练:跑 1-2 小时
  4. 测试:用 ComfyUI 加载 LoRA,出 5 张图对比
  5. 微调:效果不好改参数再训

9. 进阶 3:IP-Adapter 高级用法

9.1 多人角色场景(双 IP-Adapter)

两张参考图,每张对应一个角色。关键:用 IPAdapterRegional 节点 + 遮罩控制角色区域。

9.2 角色姿态控制(IP-Adapter + ControlNet)

[角色姿态控制节点树] LoadImage(参考姿势图) ↓ DWPoseEstimator → ControlNetApply ↓ ↓ IPAdapterUnifiedLoader KSampler ↓ CLIPTextEncode ↓ KSampler (combined) ↓ VAEDecode → SaveImage

10. 实战 1:30 秒长视频生成(LTX 2.3 风格)

传统 AnimateDiff/SVD 只能 2-4 秒。2026 主流:LTX 2.3(30-50 秒,4K 50fps)。

[LTX 2.3 长视频节点树] CheckpointLoaderSimple(ltx-video-2b-v0.9.5.safetensors) ↓ CLIPTextEncode (长镜头描述) ↓ LTXVScheduler (frames=120, fps=24) ↓ KSampler (steps=30, cfg=3.5) ↓ VAEDecodeTiled # 必须 tiled,否则 OOM ↓ VideoCombine (fps=24, format=mp4) # 关键 frames=120 = 5 秒(24fps) | frames=720 = 30 秒 LTX GGUF 量化版 8GB VRAM 可跑!

14. 性能优化技巧

⚡

10 个实测优化:
① FP8/GGUF 量化 — 大模型显存减半
② VAE Tiled — 防止 OOM
③ Batch Size — 一次跑 4 张,GPU 利用率提升
④ 关闭预览 — Preview 节点拖到 disable
⑤ xFormers / SDPA — 加速 attention
⑥ 卸载模型 — ModelMerge / FreeU
⑦ CFG 适中 — 7-8 不要 12+
⑧ Steps 控制 — 20-30 步够用
⑨ 缓存 LoRA — 同 LoRA 不重复加载
⑩ RTX 50 系列开 NVFP4 — 4 倍加速

15. 常见故障排除(7 大类)

故障原因解决
黑屏 / 没反应浏览器缓存Ctrl+Shift+R 硬刷新 / 换 Chrome
CUDA Out of MemoryVRAM 不足降低 batch / 启用 VAE Tiled / 量化
模型加载失败路径错放 ComfyUI/models/checkpoints/
插件冲突版本不兼容ComfyUI-Manager → Install Missing → 重启
出图全黑/全噪采样器错换 euler_ancestral 或 dpmpp_2m
提示词不生效CLIP 错检查 SDXL 双 CLIP 设置
视频生成失败显存爆用 LTX GGUF 量化版 / 减少 frames
