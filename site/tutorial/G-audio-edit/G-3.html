3. 工具 1 · 剪映自带配音(免费够用)

玉哥工具 1

✂️ 剪映自带 · 学员 60% 在用

位置:剪映 → 文本 → 添加文字 → 文本转语音。

3 大音色:

  • 男声 · 磁性(成熟男性角色,如"龙王")
  • 女声 · 温柔(女主 / 甜宠女主)
  • 男声 · 少年(年轻男主 / 反派年轻版)

优势:

  • ✅ 完全免费,无限使用
  • ✅ 已经集成在剪映里,不用切换工具
  • ✅ 中文识别率高

短板:

  • ❌ 音色只有 30+,多角色容易撞
  • ❌ 不能调"语速 / 情绪 / 停顿"
  • ❌ 英文发音一般

📌 适用:单角色漫剧 / 个人练习 / 学员试水。第 1 集用剪映 = 0 成本起步。

5. 工具 3 · ElevenLabs(海外剧)

玉哥工具 3 · 海外必备

🌍 ElevenLabs · 海外剧配音

官网:elevenlabs.io。29 国语言,英文 / 西语 / 日语 / 韩语配音效果最好。

学员标准用法:

  1. 写好中文剧本
  2. 用 ChatGPT 翻译成英文(让 GPT-4 翻译得更口语化)
  3. 把英文粘贴到 ElevenLabs → 选音色 → 生成
  4. 下载 MP3 → 拖进剪映对齐视频

学员海外 4 大平台用 ElevenLabs:

  • ReelShort(英文短剧)—— 70% 用 ElevenLabs
  • DramaBox —— 50%
  • FlexTV —— 60%
  • GoodShort —— 80%(国产出海)

📌 玉哥经验:国内剧用魔音,海外剧用 ElevenLabs。英文配音首选 ElevenLabs(微软 Azure 太机械,魔音英文差)。

8. 多角色配音流程(实战)

玉哥实战 SOP

🎬 1 集多角色配音 5 步走

  1. 拆剧本:在 Excel 里给每句对白标"角色 A / B / C"
  2. 角色音色分配:
    • 主角:磁性男声 / 温柔女声
    • 反派:御姐 / 老者(差异化)
    • 工具人:少年 / 中性
  3. 逐角色生成:先主角再配角(主角音色记住 → 整集一致)
  4. 导入剪映:按时间轴对位视频(台词文字 → 视频人物嘴部)
  5. 微调:剪映"音频"→ 调音量(主角比配角高 3-5 dB)

耗时:80 集漫剧 1 集配音 = 2 小时(纯 AI 生成)。

11. 常见误解

❌

"AI 配音听着假" · 部分对。剪映自带 = 较假,魔音工坊 ≈ 真人 80%,ElevenLabs ≈ 真人 90%。选对工具 = 不假。

❌

"漫剧必须有真人配音" · 错。95% 学员作品全 AI。抖音 / 红果 / ReelShort TOP 100 漫剧 中 80% 是 AI 配音(观众分不出来)。

⚠️

"用 1 个音色跑全集" · 错。多角色漫剧 = 多音色。5 个角色 = 5 种音色(主角 + 女主 + 反派 + 配角 + 旁白)。单音色 = 全剧一个声音 = 观众立刻走。

⚠️

"英文配音让 AI 直接生成" · 错。AI 直接读中文剧本 → 英文 = 蹩脚中式英语。玉哥标准 = 先翻译后配音(ChatGPT 翻 + ElevenLabs 读)。

12. 本节小练习

  1. 用剪映自带跑第 1 集对白(随便挑 10 句),听效果
  2. 注册魔音工坊免费版,挑 5 个不同音色跑同一句对白,对比差异
  3. 用魔音工坊给第 1 集 5 个角色分配不同音色
  4. 逐句生成配音,导入剪映对齐视频时间轴
  5. 导出第 1 集配音版,记录耗时 + 成本
  6. (选做)注册 ElevenLabs,把第 1 集对白翻译成英文配音
