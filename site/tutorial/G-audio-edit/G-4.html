G-4 · 多角色配音(角色分配)

1. 学员角色分配表

角色声音 ID性格语速
女 1(小美)剪映 young_female_01活泼中快
女 2(翠花)剪映 mature_female_01温柔中
男 1(阿杰)剪映 young_male_01热血中
反派剪映 deep_male_01阴沉慢

2. 多角色配音 3 步

  1. 剧本中标注说话角色
  2. 每角色一个声音文件
  3. 剪辑软件合并

3. 剧本标注法

小美: "你来了"
阿杰: "我等你好久了"
反派: "哼,来得正好"

4. 学员批量配音

  1. 用 ChatGPT 把剧本转 JSON
  2. JSON 含 role + text
  3. Python 脚本循环调 API
  4. 输出 wav 文件

5. 数字时间

操作耗时
5 角色对话配音30 分钟
10 角色对话配音60 分钟
批量脚本生成10 分钟

6. 学员避坑

  • ❌ 同一角色跨集换声音(观众混乱)
  • ❌ 反派用活泼声音
  • ❌ 主角声音弱

7. 学完能做啥

  • 能处理多角色配音
  • 会剧本标注
  • 懂玉哥批量
