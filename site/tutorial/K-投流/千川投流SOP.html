§ 0 · 投流基础 · 小白入门

🐣

本章面向从没投过流的学员。3 章覆盖投流是什么 / 千川是什么 / 投流核心逻辑。30 分钟看完能听懂别人聊"投流 / ROI / 完播率"。

0.1 投流是什么 · 一句话讲清

投流 = 花钱买平台流量,让短剧被更多人看到。你做了一部 AI 漫剧,免费挂在平台没人看;花钱让平台把你的剧推给 1 万 / 10 万 / 100 万人。有付费用户 → 赚回本 + 利润;没人付费 → 钱打水漂。

0.1.1 自然流 vs 付费流

维度自然流付费流(投流)
来源用户主动搜 / 平台推花钱买曝光
成本免费¥1-100 / 千次曝光(CPM)
速度慢,1-3 月起快,1-7 天可见
质量不稳定可控(看数据调)
比例20-40%60-80%(短剧主要靠投流)

0.2 千川是什么 · 抖音的官方投流平台

千川 = 巨量千川 = 抖音 / 今日头条 / 西瓜视频的官方广告投放平台。90% 短剧投流走千川(因为短剧主要在抖音生态)。

⚠️

重要:千川不是"千次展现"——它是抖音官方的广告投放系统。不是免费的。充值 ¥1000 起,按曝光 / 点击 / 转化扣费。

0.3 投流核心逻辑 · 3 个数字定生死

投流就 3 个数字:

数字作用健康值低于健康值怎么办
完播率观众是否看完30-40%+改前 5 秒 / 改剧情
付费率看完是否付钱5-8%+改付费卡点 / 加爽点
LTV(单用户终身价值)1 个用户付多少80-200 元改定价 / 加续作
💎

投流公式:
ROI = (完播率 × 付费率 × LTV) / CPM
例:30% × 6% × ¥100 / ¥40 = 0.45(❌ 亏本)
例:35% × 7% × ¥100 / ¥40 = 0.61(⚠️ 接近临界)
例:40% × 8% × ¥100 / ¥40 = 0.80(✅ 平衡)
例:40% × 10% × ¥120 / ¥40 = 1.20(✅ 赚钱,可投)
例:50% × 10% × ¥150 / ¥40 = 1.87(🚀 爆款,放量大)

3 个数字 1 个不能低。完播率低于 25% → 改剧情;付费率低于 3% → 改卡点;LTV 低于 50 → 改定价或加续作。

🧮

想立刻算 ROI? → 跳到 § 7.2 ROI 计算器 · 5 输入 5 输出。5 个数字 → 知道这剧该不该投 / 投多少 / 能赚多少。

6. 出价 · 5 大策略

6.1 出价公式

出价 公式: 初始出价 = LTV × 0.5 (从保守开始) 放量出价 = LTV × 0.7 (ROI 1.2+ 时) 峰值出价 = LTV × 0.8 (ROI 1.5+ 时) # 真实案例:某短剧 LTV=100 元(玉哥默认) 初始: ¥50 / 付费 放量: ¥70 / 付费 峰值: ¥80 / 付费

6.2 5 大出价策略

  1. 保守起步 — LTV × 0.5,先跑出数据
  2. 快速放量 — 跑出 ROI 1.3+ 后每日 +30% 出价
  3. 稳定不动 — ROI 1.0-1.2,保持出价
  4. 缓慢降出 — 衰退期每日 -10% 出价
  5. 重启出价 — 上新素材后回到初始出价

7. ROI 优化 · 5 大杠杆

杠杆优先级操作
① 提升完播率最高改前 5 秒 / 加悬念 / 改剪辑
② 提升付费率高加付费卡点 / 改定价 / 加钩子
③ 降低出价中衰退期 -10% 出价
④ 精准定向中缩地域 / 缩兴趣 / 缩行为
⑤ 素材多元化持续每 3 天换 1 条素材

7.1 健康 ROI 警戒线

📊

健康 ROI:
❌ ROI < 0.8 = 亏本,立刻停
⚠️ ROI 0.8-1.0 = 临界,改素材
✅ ROI 1.0-1.2 = 平衡,继续测
🔥 ROI 1.2-1.5 = 赚钱,放量
🚀 ROI > 1.5 = 爆款,峰值打

⚠️

诚实警告(玉哥 3 条血泪):
1. 5 个数字估不准很正常 — 尤其完播率 + LTV,实际 ROI 误差 ±30%。先小预算测(¥500/天 × 3 天)再放大
2. 总 ROI 1.0 不代表赚钱 — 内部"素材维度分层",可能 1 条素材 ROI 1.5 + 3 条 0.7,看分素材 ROI 不看总 ROI
3. 玉哥 1.4 ROI 是成功案例 — 实际 5 部剧里 1-2 部赚钱,3-4 部亏是常态。投前一定先算,投后一定分素材复盘

7.3 3 步用计算器决策

  1. 填 5 个数 — 完播率用平台后台数据,LTV 用 ¥100 默认(没数据时),CPM 看千川后台
  2. 看判定 banner — ROI < 1.0 别投;1.0-1.2 投 ¥1000 测;≥ 1.2 投预算;≥ 1.5 加预算拉满
  3. 投后每天复盘 — 用 § 8 复盘表分素材记录,3 天后重算 ROI,差的素材砍掉,好的素材加预算

9. 5 大常见错误

  1. 用原剧当投流素材 — 完播率掉 50%
  2. 一上来就大预算 — 没测素材就 ¥5000/天,亏光
  3. 只看总 ROI,不看分素材 — 赢家素材被输家拖累
  4. 不卡付费点 — 投流效果 = 完播率 × 付费率 × LTV
  5. 不看自然流 — 自然流好的剧投流 ROI 更好
