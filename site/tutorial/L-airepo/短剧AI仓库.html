1.1 8 类爽感(提炼)

核心:爽点本质 = 压抑 → 释放。没有前期压抑的"爽"是廉价的。

#类型情绪公式典型场景
1身份碾压轻视 → 蓄力 → 揭露 → 跪地亮军衔 / 出示证件 / 一个电话
2打脸复仇被陷害 → 隐忍 → 反击原话奉还 / 证据反杀 / 局中局
3逆袭励志低谷 → 努力 → 成功从外卖员到总裁 / 草根翻身
4甜宠撒糖误会 → 心动 → 在一起霸总独宠 / 萌宝助攻 / 闪婚
5虐心纠葛相爱 → 阻挠 → 错过误会分手 / 家族反对 / 生死别离
6悬疑反转线索 → 误导 → 真相多重身份 / 假死 / 身份揭露
7燃爆战斗挑衅 → 觉醒 → 碾压战神归来 / 都市修仙 / 异能觉醒
8搞笑吐槽误会 → 反转 → 笑点沙雕主角 / 错位喜剧 / 互怼

1.2 6 种爆款开场模板

核心:前 5 秒定生死,前 30 秒必须建立核心冲突 + 展示主角处境 + 抛出钩子。绝对禁止:大段旁白 / 慢节奏风景 / 角色日常 / 平铺直叙。

模板结构适用题材
① 直接打脸主角被羞辱 → 施辱者嚣张 → 隐忍暗示身份战神 / 逆袭 / 家庭伦理
② 身份反转角色 A 轻视 B → 立刻揭露 B 真实身份 → 反差霸总 / 萌宝 / 都市情感
③ 极端困境主角绝境 / 死亡边缘 → 转折(重生/穿越) → 二次机会重生 / 穿越 / 末日
④ 倒叙悬念从高潮切入 → 闪回原因 → 揭秘凶手悬疑 / 探案 / 复仇
⑤ 强冲突开头直接冲突(打斗/对骂) → 揭示原因动作 / 战神 / 都市
⑥ 反差展示角色表面身份 → 揭示真实身份/处境萌宝 / 闪婚 / 甜宠

1.3 5 种钩子套路

每集结尾必须有钩子。占比推荐:情绪钩 30-40% / 悬念钩 20-30% / 危机钩 10-20% / 信息钩 10-20% / 反转钩 5-15%。

  1. 悬念钩:且听下回分解 / 留伏笔
  2. 反转钩:最后一句反转(她居然没死 / 原来一切是局)
  3. 情绪钩:眼泪掉下 / 拥吻 / 摔东西
  4. 信息钩:揭露身份 / 透露关键证据
  5. 危机钩:有人敲门 / 死亡倒计时 / 更强敌人出现

1.4 4 层反派体系

  1. 小反派(前 1/4):日常对抗 / 炮灰
  2. 中反派(前 2/3):阶段威胁 / 主要对手
  3. 大反派(中后期):核心对抗 / 终极 Boss
  4. 隐藏反派(后 1/3):终极反转 / 揭露

1.5 4 段节奏曲线

段落占比任务
起势段15%建置人物 + 冲突
攀升段30%冲突升级 + 爽点密集
风暴段35%高潮 + 付费卡点
决战段20%决战 + 结局

付费卡点 💰 占比 10-15%。关键剧情集 🔥 占比 25-35%。

1.6 ⭐ 写剧本 Prompt(完整版 · 0 基础可直接复制)

点击下方代码块右上角复制,粘到 Claude/ChatGPT/Codex
📋 Prompt · 复制这条给 AI: 你是微短剧编剧,基于 0xsline/short-drama skill 撰写第 N 集剧本。 输出格式: # 第{N}集:{集标题} > 本集关键词:{3 个关键词} > 本集爽点:{8 类爽感之一,见下} > 前情提要:{上一集结尾悬念,1-2 句} --- ## 场次一 **场景:** 内景/外景 · {地点} · 日/夜 **出场人物:** {人物列表} △ (全景){场景描写,交代环境} △ (中景){人物动作描写} **{角色名}**({语气/动作指示}):"{台词}" △ (特写){关键细节描写} ♪ 音乐提示:{音乐氛围描述} --- > 🎣 本集钩子:{悬念描述} > 📺 下集预告:{下一集核心看点} 8 类爽感(本集选其一): 1. 身份碾压 / 2. 打脸复仇 / 3. 逆袭励志 / 4. 甜宠撒糖 / 5. 虐心纠葛 / 6. 悬疑反转 / 7. 燃爆战斗 / 8. 搞笑吐槽 质量要求: - 800+ 字 / 3-5 个场次 - 至少 3 种景别(全景/中景/近景/特写) - 前 30 秒必须建立冲突+展示主角处境+抛钩子 - 结尾必须有钩子 - 心理活动 → 外化为动作/对白 - 对白 ≤ 20 字/句 我的输入(请替换): - 题材:{你的题材,如"霸总甜宠"} - 集数 N:{数字,如"3"} - 本集核心爽点:{从 8 类里选,如"身份碾压"} - 上一集结尾:{简要,如"反派设下圈套,女主将出席宴会"} - 主角设定:{姓名/处境,如"林晚,被陷害入狱,刚出狱"} - 反派:{姓名/与主角矛盾,如"继母赵姐,霸占家产 10 年"} - 出场人物:{列表,如"林晚,继母,管家老陈"}

2.2 角色一致性 3 大方案(从 BigBanana 提炼)

方案原理效果
① 衣橱系统同一角色维护多套造型参考,跨集复用同一人多套衣服不串戏
② 角色定妆照为每个角色生成多张标准参考图,所有镜头生成时调用跨集脸型/发色/体型一致
③ 资产约束所有画面生成严格受角色 + 场景参考图约束AI 不"幻觉"出变形

4.1 ⭐ 17 个失败模式(必看 · 避坑)

#失败模式避坑建议
1前 3 集节奏拖前 3 集必须 5 秒内冲突,30 秒内钩子
2主角太弱主角必须有"金手指"或反差
3反派太弱反派分层,4 层递进
4钩子太弱每集结尾必须有 5 类钩子之一
5画面太乱角色一致性参考 + 场景图复用
6字幕太满关键台词加粗,情绪词用 emoji
7配音不齐11Labs 多语种质量高,魔音工坊中文准
8时长失控单集 1-3 分钟,总 30-60 集
9类型不符明确 13 类题材,选 1-2 个主类型
10价值观争议过合规审查(0xsline 有 /compliance)
11平台不收投红果/九州/七猫,看 v3.0 第 15 章
12数据不可信用千川/蝉妈妈,别自嗨
13投流无效用 v9.0 千川 SOP,小额测试
14复盘不力每部做复盘表,留数据
15续作断档首部爆款后立刻规划第 2 部
16IP 失效用番茄公开榜 + 7 猫/九州多源
17完结过晚30-60 集节奏紧凑,别拖到 100 集
