E-18 · SDXL 工作流与学员推荐模型

1. SDXL vs SD 1.5

指标SD 1.5SDXL
分辨率512×5121024×1024
模型大小2-4 GB6-7 GB
显存4 GB+8 GB+
细节一般4 倍
提示词遵循中高

2. 学员推荐 SDXL 模型

  • juggernautXL:写实 / 漫剧通吃(学员 60% 用)
  • realvisXL:极致写实
  • dreamShaperXL:动漫 / 风格化
  • counterfeitXL:二次元
  • ponyDiffusionXL:欧美动漫

3. SDXL 双 CLIP 提示词

SDXL 有 2 个 CLIP:CLIP-L(主)+ CLIP-G(辅助)。

  • 学员 70%:用双 CLIP(节点默认)
  • 30%:用单 CLIP-L(老 prompt 习惯)

4. SDXL 玉哥黄金参数

参数玉哥推荐
steps25-30
cfg7-8
samplerdpmpp_2m / dpmpp_sde
schedulerkarras
分辨率1024×1024 / 832×1472

5. SDXL 必装 LoRA

  • 角色 LoRA(学员每人 5-10 个)
  • 风格 LoRA(动漫 / 写实)
  • 细节 LoRA(皮肤 / 眼睛)
  • 姿势 LoRA(配合 ControlNet)

6. SDXL 工作流(8 节点)

  1. Load Checkpoint(SDXL 模型)
  2. CLIP Text Encode(正向,连双 CLIP)
  3. CLIP Text Encode(反向,连双 CLIP)
  4. Empty Latent Image(1024×1024)
  5. KSampler
  6. Load LoRA(可选)
  7. VAE Decode
  8. Save Image

8. 常见误解
