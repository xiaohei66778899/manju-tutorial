E-27 · LoRA 训练工具(kohya_ss / ai-toolkit)

1. 三大训练工具对比

工具支持学员用
kohya_ssSD 1.5 / SDXL60%
ai-toolkitFlux / SDXL25%
OneTrainer全模型15%

2. kohya_ss(GUI 版)

  • 仓库:github.com/bmaltais/kohya_ss
  • 支持:SD 1.5 / SDXL LoRA + DreamBooth
  • 界面:Web UI
  • 优势:教程多,社区大
  • 劣势:Flux 不支持

3. ai-toolkit(ostris)

  • 仓库:github.com/ostris/ai-toolkit
  • 支持:Flux / SDXL LoRA
  • 优势:Flux 训练最稳
  • 劣势:配置复杂

4. OneTrainer(2025 新)

  • 仓库:github.com/Nerogar/OneTrainer
  • 支持:全模型(SD 1.5/SDXL/Flux/Hunyuan)
  • 优势:界面友好,模型全
  • 劣势:相对较新

5. 安装 kohya_ss(学员最常用)

  1. git clone 仓库
  2. 运行 setup.bat(Windows)
  3. 激活 venv
  4. 运行 kohya_gui.bat
  5. 浏览器自动打开

6. LoRA 训练关键参数

参数SD 1.5 推荐SDXL 推荐Flux 推荐
network_dim326416-32
network_alpha163216
lr1e-41e-44e-4
steps150020001500
