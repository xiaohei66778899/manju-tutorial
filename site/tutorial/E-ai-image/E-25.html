E-25 · 在线出图工具横评(Midjourney / Niji / Bing)

1. 五大在线工具横评

工具价格学员用特点
Midjourney V7$10/月起60%动漫 / 写实均强
Niji V7$10/月25%二次元专用
GPT-4o$20/月10%OpenAI 多模
Bing Create免费3%DALL·E 3
通义万相免费2%国产

2. Midjourney V7(学员主力)

  • 网址:midjourney.com
  • 使用:Discord 频道输入 /imagine
  • 学员使用:漫剧封面 / 概念图
  • 优势:提示词理解力强,风格多样

3. Niji V7(二次元专用)

  • 网址:niji.midjourney.com
  • 适合:日漫 / 国漫 / 二次元
  • 学员:漫剧女主偏好 Niji
  • 注意:与 Midjourney V7 是两个独立订阅

4. GPT-4o 出图(2025 新)

  • 网址:chatgpt.com
  • 优势:理解复杂场景,文 + 图一体
  • 劣势:风格控制弱,角色一致性差
  • 学员:10%(快出图测试用)

5. 在线 vs 本地

维度在线本地
成本$10-30/月电费 + 显卡
隐私数据上传本地
速度云端(慢)本地(快)
批量受限自由
学员辅助 30%主力 70%

6. 学员组合工作流

  1. 概念图:Midjourney V7(快)
  2. 角色一致性:本地 SDXL/Flux + LoRA
  3. 批量分镜:本地出图工具
  4. 封面:Midjourney + Photoshop 排版

7. 学完能做啥

  • 能选对在线工具
  • 懂工具差异
  • 会组合本地 + 在线
