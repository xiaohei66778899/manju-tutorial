E-19 · Flux 工作流(2025 主流)

1. Flux 三版本

版本特点显存学员用
Flux Dev质量最佳12 GB+(fp8)/24 GB(fp16)50%
Flux Schnell快速(1-4 步)12 GB30%
Flux Pro商用最强API20%(API)

2. Flux vs SDXL

指标SDXLFlux
提示词遵循高极高
手部细节常崩基本不崩
文字渲染差好
模型大小6-7 GB12-23 GB
出图速度中慢

3. Flux 玉哥黄金参数

参数玉哥推荐
steps20-28
cfg3.5(SD 是 7)
samplereuler
schedulersimple / beta
分辨率1024×1024 / 1024×1792
❌

注意:Flux 的 cfg 必须低(1-4),否则图坏。

4. Flux 工作流(8 节点)

  1. Load Checkpoint(Flux 模型)
  2. CLIP Text Encode(正向)
  3. CLIP Text Encode(反向,可省)
  4. Empty Latent Image(1024×1024)
  5. KSampler(cfg 3.5)
  6. FluxGuidance 节点(学员必备)
  7. VAE Decode
  8. Save Image

5. Flux LoRA

  • Flux LoRA 训练更复杂(学员 50% 自训)
  • 官方 LoRA 库:civitai.com/tag/flux
  • Flux LoRA 通用 SDXL / SD 1.5?
  • 错:Flux LoRA 不通用

6. Flux 与 ControlNet

Flux 有专门的 ControlNet 模型(Union / Canny / Depth)。

  • 下载:lllyasviel/controlnet-v1-1 + Flux 版
  • 节点:Apply ControlNet(Flux 版)
  • strength 0.5-0.7
