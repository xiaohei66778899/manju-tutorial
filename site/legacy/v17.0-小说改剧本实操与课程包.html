6 步专业编剧流程(基于 0xsline/short-drama 改造)

基于 GitHub 顶级仓库 0xsline/short-drama(MIT 协议,9 文件 2646 行,2026-07 更新)。复制以下 6 步 Prompt 到任何 LLM(Claude/ChatGPT/DeepSeek)即可直接用。

💡 用法:① 复制命令全文(含 Prompt)→ ② 粘贴到 Claude/ChatGPT 对话 → ③ 按 AI 追问输入你的题材/小说 → ④ AI 给你结果。命令顺序: /start → /plan → /characters → /outline → /episode N → /review N。

第 1 步 · /start(选题立项)

📋 复制这条 Prompt 给 AI: 你是一位专业的微短剧编剧,精通短视频爆款创作方法论。 请引导我从选题到完稿,完成一部 50-100 集的完整微短剧。 先问我以下配置: 1. 题材(从 13 种里选,可叠加 2 种): 霸道总裁 / 甜宠 / 复仇 / 穿越 / 重生 / 悬疑 / 宫斗 / 都市 / 玄幻 / 末日 / 校园 / 职场 / 古装言情 2. 目标受众: 男频 / 女频 / 全年龄 3. 故事基调: 爽燃 / 甜虐 / 搞笑 / 暗黑 / 温情 4. 结局类型: 大团圆 / 开放式 / 反转式 / 悲剧 5. 集数规模: 50-60 紧凑 / 60-80 标准 / 80-100 长线 6. 输出语言: 中文 / English 输出格式: # 创作方向确认 - 题材组合: {题材} - 目标受众 / 基调 / 结局: ... - 集数: 集 - 输出模式: 国内 / overseas 确认后保存到 .drama-state.json,提示进入 /plan。

第 2 步 · /plan(创作方案)

📋 Prompt: 基于上面 /start 的配置,生成完整的故事骨架 creative-plan.md,包含 8 个核心板块: 1. 剧名备选(3 个,每附一句话说明) 2. 时空背景: 时代 / 地点 / 社会环境 / 阶层关系 3. 一句话故事线 + 核心冲突 4. 三幕结构: - 第一幕(建置):集数范围 / 核心事件 / 人物建立 - 第二幕(对抗):冲突升级 / 转折点 - 第三幕(高潮):终极对决 / 结局 5. 全剧节奏波形(文字描述):标注高潮点 / 低谷点 / 付费卡点 6. 付费卡点:具体集数 + 卡点类型 + 悬念设计(占比 10-15%) 7. 爽点矩阵:8 类爽感(打脸 / 逆袭 / 甜宠 / 虐心 / 悬疑 / 燃 / 搞笑 / 感动)按题材配比 8. 结局设计:主线 + 感情线 + 伏笔回收

第 3 步 · /characters(角色设计)

📋 Prompt: 基于 /plan 的故事骨架,生成完整角色体系 characters.md: 1. 主要角色档案(每个角色): - 姓名 / 年龄 / 外貌(2-3 句) - 性格关键词(3-5 个) - 公开身份 vs 真实身份 - 核心动机 - 最大冲突点 - 爽点功能(在故事中承担什么爽点) - 口头禅 2. 角色关系图(Mermaid 格式) 3. 角色弧线:从第 1 集到最后一集的变化轨迹 4. 感情线:男女主关系发展关键节点(集数标注) 5. 四层反派体系: - 第 1 层:小反派(前期炮灰) - 第 2 层:中反派(中期主要对手) - 第 3 层:大反派(终极 Boss) - 第 4 层:隐藏反派(反转用) 6. 关键互动场景预设:第一次冲突 / 身份揭露 / 感情转折 / 终极对决

第 4 步 · /outline(分集目录)

📋 Prompt: 基于 /characters,生成分集目录 episode-directory.md。每集 1 行,共 50-100 集: 第{N}集:{集标题} —— {核心冲突或爽点一句话描述} {标记} 标记: - 🔥 关键剧情集(重大转折/高潮/揭秘) - 💰 付费卡点集(设计悬念,引导付费) - 无标记 = 常规推进 硬性要求: - 前 10 集 ≥ 3 个 🔥 和 2 个 💰 - 全剧 🔥 占比 25-35% - 全剧 💰 占比 10-15% - 钩子类型分布:情绪钩 30-40% / 悬念钩 20-30% / 危机钩 10-20% / 信息钩 10-20% / 反转钩 5-15% 生成后提示用户先通读目录确认节奏再开始 /episode 1。

第 5 步 · /episode {N}(分集撰写,最关键)

📋 Prompt: 基于前 4 步结果,撰写第 N 集完整剧本,保存到 episodes/ep{NNN}.md。 单集剧本格式: # 第{N}集:{集标题} > 本集关键词:{3 个关键词} > 本集爽点:{爽点类型} > 前情提要:{上一集结尾悬念,1-2 句} --- ## 场次一 **场景:** 内景/外景 · {地点} · 日/夜 **出场人物:** {人物列表} △ (全景){场景描写,交代环境} △ (中景){人物动作描写} **{角色名}**({语气/动作指示}):"{台词}" △ (特写){关键细节描写} ♪ 音乐提示:{音乐氛围描述} --- ## 场次二... ## 场次三... --- > 🎣 本集钩子:{悬念描述} > 📺 下集预告:{下一集核心看点,1 句} 质量要求: - 每集 3-5 个场次,800+ 字(中文)/ 600+ words(English) - 景别至少 3 种(全景/中景/近景/特写) - 台词带语气或动作指示 - 每集结尾必须有悬念钩子 - 第 1 集必须在前 30 秒抓住观众 - 付费卡点集结尾必须制造强悬念 支持格式: /episode 1 单集 / /episode 5-8 批量 / /episode next 续写

第 6 步 · /review {N}(质量审查,5 维评分)

📋 Prompt: 对第 N 集进行质量审查,保存到 reviews/ep{NNN}-review.md。 5 维评分(每项 1-10 分): | 维度 | 检查内容 | |---|---| | 节奏 | 开场是否够快、有无拖沓段落、紧张-舒缓交替 | | 爽点 | 数量 / 强度 / 类型多样性 | | 台词 | 有无废话 / 角色区分度 / 口语化 | | 格式 | 场景头 / 景别 / 音乐提示 / 标记 | | 连贯性 | 前后集矛盾 / 角色一致 / 伏笔延续 | 评级: 45-50 优秀 / 35-44 良好 / 25-34 及格 / 25- 不合格 输出格式: # 质量自检报告 - 第{N}集 ## 评分 | 维度 | 得分 | 说明 | | 总分 | X/50 | ## 问题清单 1. [严重/建议] {问题} → {建议} ## 修改建议 {按优先级排列}

完整工作流(复制这一段给 AI 当指令)

📋 一条龙 Prompt(粘到 Claude/ChatGPT,完整走 6 步): 你是微短剧编剧,严格按以下 6 步流程帮我创作: 1. /start:问 6 个配置(题材 / 受众 / 基调 / 结局 / 集数 / 语言) 2. /plan:输出 creative-plan.md(8 块) 3. /characters:输出 characters.md(角色 + 4 层反派) 4. /outline:输出 episode-directory.md(分集目录 + 标记) 5. /episode N:输出 ep{NNN}.md(剧本,800+ 字) 6. /review N:输出 5 维质量评分 每步完成后等我确认再进入下一步。 我的输入:{题材=复仇, 受众=女频, 基调=爽燃, 结局=大团圆, 集数=60, 语言=中文} 我的小说/创意:{粘贴你的小说开篇 1 章或 1 句话创意}

真实改编示范(通用爽文开篇)

来源:sheratonhq.com 工程化指南示范段(非《我不是戏神》实际内容,套用模板改你自己的书)。

3.1 原文(180 字,典型水文)

林凡 废柴逆袭开篇 林凡攥紧了拳头,指甲深深掐进了掌心,传来一阵刺痛。他心中涌起滔天的怒火与不甘:"三年了,我为家族付出一切,如今只因一次失败就要将我像野狗一样赶出去吗?" 他想起这三年来日夜修炼,却因资质平平而进展缓慢,那些冷眼和嘲笑如同冰锥刺在他的心上。夜空中的星星冷冷地闪烁着,仿佛也在嘲笑着他的无能。 心理 60% · 环境 20% · 动作 20%

3.2 拆解

动作: 攥紧拳头,指甲掐进掌心 → 保留 心理: 怒火与不甘的内心独白 → 外化为台词 回忆: 三年付出/资质/冷眼 → 删(前置或后叙) 环境: 夜空星星隐喻 → 简化为"夜"

3.3 改编后(500 字剧本,60-90s)

短剧第 1 集 · 林家议事厅 → 林家庭院 【0-3s】特写:一份"驱逐令"被拍在檀木桌上。 【3-10s】林家众长老围坐,面色冷漠。林凡站在厅中,单薄身影与森严大厅形成对比。 【10-15s】二长老(冷笑):"林凡,家族不养废人。即日起搬出内院,去杂物房吧。" 【15-25s】林凡身体一震,抬头,眼神从难以置信变为屈辱。 【25-30s】林凡(低声):"…是。" 转身离开,拳头在袖中紧握。 【30-40s】镜头跟随他走出议事厅,刺眼阳光让他眯了下眼。厅内传来隐约讥笑声。 【40-90s】场景:林家庭院 - 夜 - 外 林凡独自站在院中,身体微微颤抖。他紧紧攥着拳头,指甲深深陷入掌心。 林凡(低声,充满不甘):"三年…就换来这个下场。" 他猛地抬头望向漆黑的夜空,眼中闪过一抹倔强与恨意。 【结尾钩子 5s】院外传来脚步声。林凡警觉回头。【镜头定格双眸特写】黑屏字幕:"他不知道,今夜,戒指会苏醒。" 动作 60% · 对白 40% · 心理 0% · 环境 0%

3.4 关键转换对照

类型原文剧本
心理独白"三年了,我为家族付出…""三年…就换来这个下场。"(压缩 90%)
回忆背景日夜修炼/资质/冷眼全部删除(留给后续集数)
环境隐喻星星嘲笑他无能"漆黑的夜空"(只保留场景)
结尾钩子(无)脚步声 + 戒指苏醒字幕

关键洞察:短剧剧本里所有心理活动必须外化为"动作 + 表演提示 + 短对白"。这就是"删 70% 留 10% 加 20%"的真实含义。

曹剑公式 · 黄金 1 分钟

来源:中国电视艺术家协会副会长曹剑 2026 讲座。

4.1 单集 60 秒节奏

0-5s 冲突前置 # 3 秒抓人 5-30s 身份反转/关键信息揭示 # 30 秒立人物 30-60s 爽点/情绪高潮 # 60 秒给结果 60s 首尾双钩子 # 锁观众看下一集

4.2 1-3-10-16 标准化拆解(整剧)

  • 1 句话:提炼核心卖点(编辑 10 秒看懂)
  • 3 个核心爆点:第 1/2/3 个付费点(把控流量节奏)
  • 10 集为单元:每 10 集 1 个情绪循环递进
  • 16 节拍:单集按 60 秒节奏(0/5/30/60 + 8 个中间点)

4.3 12 种结尾钩子套路(选 3-4 种轮换)

  1. 身份揭露(他是 XXX 的儿子)
  2. 死亡倒计时(还剩 3 天)
  3. 悬念反转(她居然没死)
  4. 神物觉醒(戒指亮了)
  5. 反派升级(更强的来了)
  6. 真相大白(原来一切都是局)
  7. 危险逼近(有人敲门)
  8. 时空转换(3 年后)
  9. 情感爆发(他哭了)
  10. 误会加深(她以为他出轨)
  11. 贵人出现(老人出手)
  12. 选项悬念(她选 A 还是 B)

4.4 60-90 秒 1 个爆点(梨花颜)

500 字/集,1-2 分钟。30 集剧本至少 20-30 个明确标注的爆点。
