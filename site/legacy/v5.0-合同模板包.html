一、通用合同框架(5 大类共性)

📐 5 大类合同的 12 个通用条款

  1. 合同主体:甲乙双方完整信息(公司名/法人/统一社会信用代码/地址)
  2. 合同标的:明确"做什么"(剧本/演出/拍摄/发行)
  3. 期限:起止时间(尤其海外 IP,建议 5 年起步)
  4. 地域:全球/中国/独家/非独家
  5. 权利范围:改编/演绎/发行/传播/衍生品/广告植入
  6. 报酬:基础报酬 + 分成 + 结算周期 + 税
  7. 署名:编剧/导演/演员/原著 怎么署名
  8. 知识产权:归属(创作方/委托方/共有)
  9. 保密义务:剧本/演员/片酬/数据
  10. 违约责任:逾期/质量/泄密/侵权的赔偿
  11. 争议解决:仲裁机构(北京仲裁委/中国国际经济贸易仲裁委)
  12. 其他:不可抗力/合同变更/通知送达
💡

谈判核心原则:① 报酬 = 基础 + 分成 + 期权(光给基础=亏)② 地域 = 全球独家 + 期限 = 5 年(避免"授权范围模糊"被转卖)③ 署名 = 必须白纸黑字(避免后期被改)④ 争议 = 仲裁优先(比诉讼快 3 倍)。

① 剧本版权合同 · 关键条款清单

📝

本类合同分两种:A. 原创剧本《著作权归属合同》; B. 改编剧本《IP 授权合同》(基于番茄小说改编)。

1.A 原创剧本《著作权归属合同》

# 原创剧本《著作权归属合同》关键条款 【1. 合同主体】 甲方(委托方/制作方):[公司全称] 乙方(编剧):[真实姓名 + 身份证号] 【2. 标的剧本】 剧本名:[《XXX》] 集数:[80 集] 单集时长:[1-3 分钟] 创作时间:[2026-09-09 至 2026-10-09] 【3. 著作权归属】 ★ 关键条款 优先方案 A:著作权归甲方,乙方保留署名权(编剧)+作品完整权(不修改原作) 次选方案 B:著作权共有,任何一方商用需对方书面同意,收益按 X:Y 分配 【4. 报酬】 基础报酬:[¥5-20 万](分 3 期:签约 30% / 交稿 40% / 上线 30%) 分成:[上线后净收益的 10-20%] 结算周期:★ 月结 / 60 天结算(避免 90 天+) 【5. 署名】 编剧署名位置:★ 片头 / 海报 / 平台页 署名形式:[编剧:XXX](不可省略) 【6. 改编权】 甲方有本剧的拍摄/发行/海外发行/衍生品权利。 ★ 关键:乙方保留"二次创作"权利(可基于本剧本写续作,但需甲方书面同意出版) 【7. 保密】 剧本未公开前,乙方不得向第三方披露。 违约:[违约金 ¥10 万] 【8. 违约责任】 甲方逾期付款:[每日 0.5% 滞纳金] 乙方逾期交稿:[每日 0.3% 赔偿,超 15 天甲方可解约] 乙方抄袭:[全部报酬退还 + 违约金 ¥50 万 + 法律责任] 【9. 争议解决】 北京仲裁委员会仲裁 【10. 合同生效】 双方签字盖章后生效,一式两份

1.B 改编剧本《IP 授权合同》

# 改编《IP 授权合同》关键条款(番茄小说 → 短剧) 【1. 合同主体】 授权方(番茄 IP):[字节跳动 / 番茄小说运营公司] 被授权方(制作方):[你的公司] 原著作权人(小说作者):[作者名] 【2. IP 信息】 小说名:[《XX》] 作者:[XXX] 授权内容:[基于本小说改编为短剧剧本的权利] 【3. 授权范围】 ★ 关键条款 · 必须明确 - 改编权:可对小说进行增删/调整/重塑 - 摄制权:可拍摄为短剧(集数/时长/平台:红果等) - 发行权:可在中国大陆 / 全球 发行 - 信息网络传播权:可通过网络平台发布 - 衍生品权:可开发周边/手游/漫画 - 海外发行权:可翻译为外文/授权海外平台 【4. 授权性质】 ★ 关键: - 优选独家:独家授权(同 IP 不能给其他方) - 避免非独家:同 IP 多方改编 = 价值被稀释 【5. 授权期限】 ★ 关键: - 建议 5 年(便于系列化+海外发行) - 避免 1 年以下(回本周期不够) 【6. 授权费用】 保底授权费:[¥5-20 万](一次性) 分成:[净收益 5-15%] 结算周期:★ 60 天结算 【7. 原著署名】 ★ 关键:原著作者必须在片头/平台页/海报显著位置署名 形式:["原著:XXX"] 【8. 改编署名】 改编编剧必须在片头署名 形式:["改编:XXX"] 【9. 内容审核】 甲方(番茄)对改编剧本有审核权 但不得无理拒绝(需在 5 个工作日内反馈,逾期视为通过) 【10. 续作权】 ★ 关键: - 优先续作:本剧爆款后,制作方有续作优先权(同 IP 续作) - 续作费按市场价 70%(独家续作的优惠) 【11. 违约责任】 任何一方违反条款,违约金 ¥50 万起 争议:北京仲裁委员会
✅

谈判要点:① 原著署名必须保留(行业惯例) ② 续作权必须锁定(系列化是 2025 后主流) ③ 审核权不得无理拒绝(避免无限期拖延) ④ 分成比例 5-15%(太高的可能是非独家)。

③ 导演/编剧《委托创作合同》关键条款

# 导演/编剧《委托创作合同》关键条款 【1. 合同主体】 甲方(制作方) 乙方(导演/编剧) 【2. 委托内容】 - 编剧:为《XX》撰写 80 集短剧剧本 - 导演:为《XX》提供导演服务 【3. 工作内容】 编剧: - 大纲:5-10 页(角色 / 主线 / 副线 / 卡点) - 人物小传:5-8 个主要人物(300-500 字/个) - 分集大纲:每集 200-300 字 - 完整剧本:80 集,单集 800-1500 字 - 修改:根据甲方反馈修改 3 轮内免费 导演: - 分镜表:每集 30-60 个镜头 - 现场执导:拍摄期间驻场 - 后期指导:剪辑/调色/特效指导 【4. 工作时间】 - 编剧:[30-60 天] - 导演:[拍摄前 7 天 + 拍摄期 + 后期 7 天] 【5. 报酬】 编剧:[¥5-20 万] + [净收益 5-15% 分成] 导演:[¥1-5 万/部,小剧组 0.5-2 万] + [爆款奖 ¥5-20 万] 头部编剧/导演:[年薪 100-200 万](腾讯新闻 2025 数据) 【6. 知识产权】 优选:作品完整版权归甲方,乙方保留署名权+作品完整权 避免:乙方"转让全部权利"——连署名权都丢 【7. 署名】 编剧:["编剧:XXX"] 导演:["导演:XXX"] 位置:片头显著位置 / 海报 / 平台页 【8. 保密】 剧本未公开前,不得对外披露 违约金 ¥10-50 万 【9. 违约责任】 逾期交稿:[每日 0.3% 赔偿,超 15 天甲方可解约] 质量不达标:[3 次修改机会,3 次后不达标可解约但支付 50% 报酬]

④ 投流方《分账合作协议》关键条款

# 投流方《分账合作协议》关键条款 【1. 合同主体】 甲方(制作方/版权方) 乙方(投流方/发行方) 【2. 合作内容】 乙方负责: - 投流:在巨量千川/磁力金牛/视频号广告等平台投放 - 素材制作:剪辑投流专属素材 - 账户运营:开广告户/充值/优化 甲方提供: - 短剧成片: - 授权书: - 物料:海报/剧照/宣发素材 【3. 投流预算】 总预算:[¥10-100 万](根据剧质量) 分阶段: - 冷启动期:[¥1-3 万](测素材) - 放量期:[¥5-20 万] - 峰值期:[¥10-50 万] 【4. 成本承担】 ★ 关键: - 投流成本:[由乙方先行垫付,后期从分账中扣除] - 制作成本:[甲方承担] - 演员片酬:[甲方承担] 【5. 分账比例】 ★ 关键: 投流方:[40-60%] 制作方:[40-60%] 编剧/演员(头部):[从制作方 40% 中分] 【6. 结算】 ★ 关键: - 结算周期:[月结 / 60 天结算] - 对账机制:[双方共享千川后台数据,共同确认 ROI] - 退款机制:[广告退款按比例分摊] 【7. ROI 兜底】 建议约定: - 若投放期间整体 ROI < 1.0(亏本),双方协商是否继续投 - 若连续 30 天 ROI < 0.8,乙方有权停止投放 - 停止投放后,剩余投流成本由乙方承担(不向甲方追讨) 【8. 素材归属】 建议: - 投流素材著作权归乙方(因为乙方出资) - 甲方有本剧使用权(可在本剧任何投放中使用) - 乙方不得将素材用于其他剧 【9. 排他性】 ★ 关键: - 优选非独家:本剧可同时授权其他发行方 - 避免独家:独家 = 投流方拿走全部话语权,甲方议价权归零 【10. 违约责任】 乙方未按预算投放:[按未投放金额的 10% 赔偿] 乙方数据造假:[全部收益归甲方 + 违约金 ¥50 万] 甲方擅自投放:[按已投放金额的 50% 赔偿乙方]

# 海外发行《本地化合作协议》关键条款 【1. 合同主体】 中方(国内制作方) 外方(海外发行方,如 ReelShort / DramaBox) 【2. 发行内容】 剧名:[《XX》] 集数:[60-80 集] 本地化版本:[英 / 西 / 法 / 阿 / 日 / 韩 / ...] 【3. 本地化范围】 外方负责: - 翻译:中文 → 目标语言(必须保留情绪) - 配音:目标语言配音(AI 或真人,$120/分钟) - 字幕:SRT 英文 - 文化适配:删除/调整文化敏感内容 - 演员本地化:中国面孔 → 欧美/拉美/中东面孔(AI 换脸) - 算法适配:根据目标平台算法调整 【4. 合规要求】 ★ 必填 · 不可漏 - FTC 自动续费提示:符合美国联邦贸易委员会要求 - GDPR 数据合规:用户数据存 AWS 弗吉尼亚节点(不在中国) - AI 合成演员 Disclosure:主演若是 AI 合成,需显著标注"Digital Actor" - 宗教/政治红线:中东版删教会阴谋;拉美版增加家庭伦理 - 演员非亚裔比例:主演非亚裔 ≥ 70%(ReelShort 要求) - ICP 备案:中国境内主体必办《网络文化经营许可证》 - 跨境文化出口许可:中国出海需文化部审批 【5. 发行期限】 建议 5 年(ReelShort 经验) 【6. 发行地域】 - 美国/英国/加拿大/澳大利亚(主要市场) - 拉美(西语市场) - 东南亚(马来/泰/印尼/越南) - 中东(阿拉伯语,需特殊合规) 【7. 报酬】 合作方式二选一: 方式 A:版权买断 - 一次性支付 [¥8-15 万/部] - 海外所有收益归外方 - 中方不再参与分账 方式 B:联合运营分成 - 前期投入 [¥3-5 万](本地化制作费由中方垫付) - 后期按月结算,中方拿 [30-50%] 分成 - 回本周期 [4.2 个月](ReelShort 经验) - ROI [1:2.3] 【8. CPM 收益】 - 基础播放量结算:$0.04-0.08/千次观看 - 付费解锁:$0.99/集起,创作者分 [30-50%](签约等级浮动) - 7 天免费试用 + 自动续费会员 【9. 演员授权跨境】 ★ 关键: - 演员肖像权需跨境授权(ReelShort 经验) - 授权期限 ≥ 5 年(避免衍生品/二创受限) - 演员需签《肖像权全球授权书》 【10. 备案与许可】 中方负责: - 中国《网络文化经营许可证》 - 跨境文化出口许可 - 演员授权 + 版权登记 - 与外方通过境内代理签约(不接受个人直接签约) 【11. 争议解决】 新加坡国际仲裁中心(SIAC)(跨境首选) 或香港国际仲裁中心(HKIAC)

⚠️ 5 大常见陷阱条款 · 必看

🚨

5 大常见陷阱——签字前必须看清,必要时请律师审核:

1

"全部权利归甲方"

陷阱:连署名权、改编权、衍生品权全部归甲方,作者彻底沦为"工具人"。
应对:必须保留署名权 + 作品完整权(原作不能被恶意修改)。

2

"永久独家"

陷阱:授权期限写"永久",等于卖身契。
应对:必须限定5 年 + 自动续约需双方同意。

3

"甲方可单方面解约"

陷阱:甲方想解就解,但乙方不行,严重不平等。
应对:必须双方解约条件对等。

4

"数据归甲方"

陷阱:所有投流数据、用户数据、收益数据归甲方,乙方无知情权。
应对:必须双方共享数据 + 月度对账。

5

"巨额违约金"

陷阱:乙方违约金 ¥100 万起,甲方违约金 ¥1 万。
应对:必须双方违约金对等。

谈判自检清单 · 签字前 5 分钟必过

# 合同签字前 · 5 分钟自检 # === 主体审查 === □ 对方公司名/法人/统一社会信用代码 与 工商信息一致? □ 对方公司是否真实存在?(查天眼查/启信宝) □ 对方是否被列入失信名单?(查中国执行信息公开网) # === 关键条款审查 === □ 著作权归属:明确归属方,保留署名权 □ 授权期限:具体年数,避免"永久" □ 授权地域:明确范围,避免"全球独家"过度授权 □ 授权范围:列明具体权利,避免"全部权利" □ 报酬:基础 + 分成 + 结算周期,避免"按甲方决定" □ 结算周期:月结/60 天结,避免"90 天以上" □ 违约责任:双方对等,避免单方面加重 □ 争议解决:仲裁优先(快),避免"诉讼"慢 # === 隐藏条款审查 === □ 是否含"自动续约"条款? □ 是否含"排他"条款? □ 是否含"竞业禁止"条款? □ 是否含"知识产权转让"条款? □ 是否含"肖像权 / 隐私"条款? □ 是否含"不可抗力"条款? # === 数字与公式审查 === □ 数字(金额/期限)是否与谈判一致? □ 公式(分成/结算)是否清晰? □ 税(个人/公司)由谁承担? # === 兜底条款 === □ 是否有"合同变更须书面同意"? □ 是否有"通知送达地址"? □ 是否有"合同份数与生效"? □ 是否有"附件清单"(剧本/演员表/物料)? # === 最终签字前 === □ 自己读一遍(别只看律师意见) □ 重要条款手写修改(避免"以最后一份为准"陷阱) □ 一式两份,双方各执一份 □ 加盖公章 / 法人签字 □ 拍照 / 扫描存档 3 份
