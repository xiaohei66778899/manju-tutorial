D1 四节拍钩子框架（冷开场→揭示→反转→掐断）

MiniMax H3 · 即梦 · Kling 来源

竖屏短剧前 15 秒留人：四节拍把冲突压缩成镜头清单。

图片1 锁定女主的脸。图片2 锁定男主的脸。
9:16 竖屏短剧场景，[场景描述，如"夜晚的豪华现代顶层公寓"]，电影感主光。
切镜1，中景：[角色A]在[动作，如"玻璃桌前签署一份文件"]，[细节，如"双手微微颤抖"]。
切镜2，过肩：[角色B]站在[位置]注视，[神情描述]。
切镜3，[角色A]的特写：[动作，如"她抬起头说"]："[台词]"。
切镜4，[角色B]的特写：[微表情]。[他/她说]："[台词]"。
定格在[角色]的眼神上。对白下铺[音乐情绪]，[环境底噪]。

四节拍：冷开场（0-3秒）→ 揭示（3-8秒）→ 反转（8-13秒）→ 掐断（13-15秒）
每镜点名景别；台词逐字写；像测广告一样测钩子

D2 五种钩子公式 + 八种悬念结尾 + 三段式剧本模板

ChatGPT · Claude · Gemini 来源

批量产出结构化短剧剧本：系列圣经 → 分集大纲 → 单集剧本。

第一步 — 系列圣经：
为一个 [类型] 短剧创建系列圣经，共 [集数] 集，包含：
- 一句话梗概
- 主角成长弧线
- 3 个动机清晰的重要配角
- 5 个主要剧情转折点
- 驱动每一集的核心冲突
- 最终结局

第二步 — 分集大纲：
基于 [系列圣经]，为第 1–10 集列出大纲，每集包含：
- 开场钩子（第一句台词）
- 本集核心冲突
- 悬念结尾（最后一刻的具体画面）
每集控制在 90 秒以内。

第三步 — 单集剧本：
为第 [X] 集写完整剧本，要求：
- 60–90 秒的对白/动作
- 开场 3 秒抓住注意力的钩子
- 结尾用悬念清单中的一种：[粘贴悬念类型]
- 角色不超过 3 个
- 每句台词推进剧情或揭示人物
用剧本格式输出，带场景标题。

五种钩子：身份反转 / 绝境开局 / 隐藏身份 / 倒计时 / 震惊性揭示
八种悬念结尾：身体危险 / 揭示 / 抉择 / 登场 / 背叛 / 倒计时 / 情感告白 / 反转
在解决方案出现之前切；每集 ≤3 角色；悬念类型轮换

D5 全局角色锁定 + 8 场景时间码模板（含负向约束）

Seedance · Runway · Kling 来源

角色跨镜头漂移：身份合同锁形象 + 8 场景时间码 + 负向约束。

全局角色一致性：
参考角色：
[年龄与身份]，[发型与颜色]，[瞳色或关键面部特征]，
[体型]，身穿 [上装]，[下装]，[配饰]，[鞋]。
在每个场景中保持完全相同的脸、发型、服装、身体比例、颜色和 [画风]。

场景1（0-2秒）— [开场地点]：
[角色] 坐在/站在 [早晨场景] 中，准备 [主要活动]。
使用 [时间段]、[房间/环境细节]、电影感灯光、浅景深、缓慢推镜。保持角色身份与 [画风] 一致。

场景2（2-4秒）— [准备特写]：
[具体动作] 的特写，带有 [情绪]。强调 [布料/手/物品/面部细节]，
柔和光线，写实质感，电影感景深，平滑手持运镜。

场景3（4-6秒）— [出发转场]：
角色从 [家/起点] 走向 [目的地]，携带 [主要道具]。
使用 [室外光线]、[街道/风景细节]、长阴影、电影感跟拍。

场景4（6-8秒）— [路途节拍]：
角色继续穿过 [路线/环境]，仍携带/使用 [主要道具]。
加入 [树木/城市/走廊/人群/天气细节]，适当时加轻微镜头光晕，写实运动，平滑跟拍。

场景5（8-10秒）— [主要动作地点]：
角色在 [主要活动地点] 执行 [主要动作]。
使用动态跟拍、明快节奏、明亮的电影感灯光、写实运动模糊，保持角色身份一致。

场景6（10-12秒）— [高光动作]：
角色在 [特定障碍/场景] 上方/穿过/旁边完成 [招牌动作或戏剧性动作]。
使用戏剧性低角度镜头、[背景细节]、写实物理、电影感慢动作。

场景7（12-14秒）— [情绪远景]：
角色在 [最终观景处/沉思地点] 停下或伫立，面向 [方向]。
使用 [天空颜色]、柔和的环境动态、电影感远景、情绪化氛围。

场景8（14-15秒）— [最终特写]：
角色面部的极特写。展示 [眼神反射或表情细节]、[头发/衣物动态]，
温暖的电影感光线，浅景深，安静收尾的表情。

风格与输出：
[画风]，电影感灯光，[主光源质量]，[构图与画幅]，适当时加入体积光或大气纵深，
平滑运镜，浅景深，写实质感，高级调色，角色身份一致，[输出分辨率与格式]。

负向约束：
场景之间不得改变脸、发型、服装颜色、身体比例、年龄或主要道具。
避免多余角色、随机换装、面部特征闪烁、无法辨认的手、物理穿帮、文字叠层、Logo 和水印。
先填身份锁；能传参考图就传；先测第 1/5/8 镜

D6 F.O.R.M.S 长视频框架 + 多镜头配置表 + 对白写法

Kling 3.0 / Omni 来源

10–15 秒多镜头叙事结构：F.O.R.M.S 五支柱 + 逐镜配置表。

F.O.R.M.S 框架：
焦点 = 角色 A 和角色 B
结果 = 一场关于秘密的对话
真实感 = 电影级画质，4K 纹理
运动 = 缓推 + 正反打镜头
场景 = 别墅室外露台

多镜头配置表（自定义多镜头模式）：
镜头1 | 欧洲别墅远景定场 | 3 秒
镜头2 | 女人搅动果汁的特写 | 4 秒
镜头3 | 男人回应的中景 | 3 秒

对白写法要点：
写明说话人名字，把每句台词放在说话角色附近。
用平实文字标注语言、语气、表演方式和相关音效，让多角色场景容易跟上。
先写动作再写台词（例如：角色先猛拍桌子，再发问）。
加入呼吸、眨眼等微动作，增强真人感。
先写场景再写动作；对白先写动作再写台词

即梦 Seedance 2.0 / 2.5 来源

## 角色 + 参考图
- 角色A（主角）：@图片1 — [外貌、服装、年龄描述]
- 角色B（配角）：@图片2 — [外貌、服装描述]
- 场景参考：@图片3 — [环境描述]

## 背景介绍
[前情、环境、情绪氛围，交代当前场景的上下文]

## 镜头描述
镜头1（0-3s）：[景别]，[画面内容]，角色A [动作]，角色A："[台词]"，[运镜]
镜头2（3-6s）：[景别]，[画面内容]，角色B [动作]，角色B："[台词]"，[运镜]

## 声音设计
- BGM：[风格/乐器/节奏变化，如"低沉钢琴单音渐入 → 吉他弦乐加入 → 大提琴到达最温暖处"]
- 环境音：[按时间段标注，如"0-9s 键盘敲击+空调嗡鸣；9-15s 鸟鸣+引擎启动"]
- 对白/旁白（二选一或混用，必须写完整文案）：
  - 对白：写在镜头描述中，角色A："完整台词"（即梦自动口型同步）
  - 旁白：按镜头标注完整旁白文案
- 音色参考：[音色和语气，如"年轻女声，语气轻松自然" / "音色参考@视频1中的男声"]

## 风格指令
[统一视觉风格：质感、色调、光线、景深等]

## 禁止项
禁止出现文字、水印、LOGO
禁止"后期叠加""后期添加""外部工具处理"等指示

台词密度规则：约 3 字/秒，单句 ≤15 字（最优 8–12 字）；3s 镜头 ≤9 字，5s 镜头 ≤15 字，10s 镜头 ≤30 字。禁止书面语连词（"然而""综上所述"），优先动词和第二人称"你"。
每个角色独立绑一张参考图；对白写在镜头描述里；金句/反转放视频 2/3 处

D3 相机提示词公式 + 三节拍序列（Runway 官方）

Runway · Veo · Kling · 即梦 来源

构图不可控：按公式拼装景别+角度+运动+主体+光线。

[景别] + [角度] + [运动 + 方向 + 速度] + [主体与动作] + [镜头/质感] + [光线/氛围] + [这个镜头揭示什么]

范例：中景，低角度，4 秒缓慢推镜，侦探在雨中点燃香烟，35mm 镜头浅景深，霓虹倒影。推镜揭示他脸上的紧张。

三节拍序列：
节拍1 — 定场：远景，高角度，镜头锁定。夜晚，女人背对镜头走进狭窄小巷，沥青路面湿润，一盏钠灯形成朦胧光晕。
节拍2 — 推近：中景，高角度，6 秒缓慢推近。她身后有人从门廊走出，轻轻跟随。女人停下脚步。
节拍3 — 揭示：切至极特写，低角度，女人转身面向街灯。她微笑，两颗尖牙在光中闪亮。

D4 四种相机提示词模式（含 Omni 多镜头表）

Kling 3.0 / Omni 来源

精确控制推、拉、摇、移的官方句式，多镜头逐镜指定。

模式1 — 主体 + 相机运动 + 目的：
相机缓慢推近 [主体]，强调 [细节或情绪]。
例：相机缓慢推近正在摆盘甜点的厨师，强调最后的点缀，写实厨房灯光。

模式2 — 起始帧 + 结束帧：
从 [特写/全景] 开始，然后 [相机运动]，揭示 [最终画面]。
例：从表盘特写开始，然后拉远，露出完整手腕和深色影棚背景。

模式3 — 相机运动 + 速度 + 稳定性：
缓慢、稳定地向左横摇 [场景]，无突然运动。

模式4 — Omni 多镜头分镜表：
镜头1：远景定场，静态机位。
镜头2：缓慢推近主体。
镜头3：俯拍下摇，揭示产品细节。
镜头4：拉远收尾。
每镜一个主运动；Omni 用分镜表逐镜写

D8 电影级提示词指南：景别情绪 + 运镜 + 动态转场

Sora · Runway · Kling · 即梦 · Luma 来源

每种景别、运镜对应的叙事情绪，含组合范例与转场。

景别与叙事情绪：
特写：以主角面部特写开场，捕捉每一个坚定的微表情。
过肩：切换到导师观察学徒工作的过肩镜头。
高角度：用高角度镜头拍摄独自站在空旷田野的英雄，强调其孤立。
低角度：用低角度镜头表现 CEO 向人群讲话的威压。
荷兰角：切到巷道的荷兰角镜头，传达迷失与危险感。

运镜与叙事功能：
向古董音乐盒推近，在它打开时加剧观众的好奇。
横摇扫过天际线，缓缓揭示隐藏的屋顶花园。
从大笑的人群甩镜到震惊的评委，强调气氛突变。
从村庄广场上方摇臂下降，进入市集的喧嚣。
用稳定器镜头跟拍走廊里的跑者，始终对准他的脸。

组合范例：
"以主角站在悬崖边的广角过肩镜头开场。缓缓推近，他把手伸向谷底。然后下摇，揭示下方蜿蜒的河流。最后切到他坚定表情的特写，放大每一个细微情绪。"

动态转场：
用甩镜模糊，将场景无缝过渡到下一地点。
角色跃过缺口时加入慢动作，强调这一刻的分量。
仰拍=权力，俯拍=脆弱；转场首选甩镜

D10 Kling 3.0 Omni 原生音频对口型写法（官方）

Kling 3.0 / Omni 来源

台词直接写进提示词、用引号，紧跟说话人 + 情绪语气。

结构：{场景 + 环境声}; {角色} {情绪/语气副词}, "{台词}"; {下一角色} {语气}, "{台词}"

官方原例：
室内家庭环境，客厅空调轻微底噪，真实日常感；
母亲轻声惊呼、带着意外的语气，"哇，这个剧情完全没想到。"；
父亲压低声音、平淡地回应，"是啊，完全没想到，真没想到会这样。"；
男孩欢快地说，"这是最棒的反转！"；
女孩兴奋地点头，"我简直不敢相信他们这么做了！"

要点：台词不单独开文本框；人名+语气+引号台词三者紧贴；情绪副词只在对剧情重要时加。
多说话人场景把人名、台词、语气写在同一处，模型据此把口型绑到对应角色

D11 Seedance 情绪/语调/语速三要素 + 多人对话格式（官方）

即梦 Seedance 1.5 Pro 来源

U3 外科手术式负面提示词法（Hailuo 官方）

支持负面词字段的模型 来源

负面词堆一长串反而破坏一致性：先渲染再观察，只针对一个缺陷精准补刀。

五步法：初版渲染 → 识别缺陷 → 精准修正 → 运动校准 → 迭代精修

1. 只用正向提示词 + 高质量参考图，生成 4–6 秒初版；
2. 观察初版，只找出一个最突出的缺陷（抖动/塑料皮肤/过饱和）；
3. 只添加一个精准负面词：
   过饱和 → 过饱和、霓虹、高对比（oversaturated, neon, high contrast）
   塑料质感 → 塑料、反光、人工反射（plastic, shiny, artificial reflections）
   画面抖动 → 抖动、背景扭曲（jitter, background warping）
4. 若运动被抑制，移除负面词，改为强化正向运动描述（如把"平移"改为"缓慢、稳定的电影感平移"）。

长序列延伸法：

✅ "平滑、稳定的相机运动"

避免时间引用：不要用"然后""接着""之后"，每条提示词相互独立。
